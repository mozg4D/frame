# Frame r180 Slice engineering

The release moves heavy inset/template preparation and complete-layer adaptive, finite-bank, neck and finalization checks to persistent helpers. The owner retains source preparation, intersections, contour stitching/normalization, canonical cache reservations and ascending output/reference registration. A helper receives a complete global layer; the cumulative additional-overlap budget stays coupled across its material components.

The shared heavy-work budget is max(1, hardwareConcurrency - 1), including the owner, finalizers and nested surface/Boolean/support pools. A low-poly job can activate the pool after a measured heavy first layer; the former 50,000-triangle gate is removed. Main transport leases every helper preparation and finalization job. Cancellation, generation changes and errors terminate every worker, close ports, revoke Blob URLs and release outstanding leases. No automatic Slice follows a source change.

Determinism depends on the original activeSet insertion order (start layer, then original triangle ID), unchanged global face/triangle/layer IDs, and canonical inset reservation order. A cached inset remains eligible only when cached.inputVertices >= current inputVertices; the rounding reserve uses the complete layer's input vertex count. Pending cache hits await the original canonical reservation. References are emitted by the owner in global order. Physical per-worker cache observations are reported separately in finalizerDiagnostics, including the owner, rather than being presented as placement-independent counters.

Memory admission uses conservative object/buffer estimates, not a measured JavaScript heap bound. Each job/reply is limited to 4 MiB; owner queued input/canonical reservations to 128 MiB and output reservations to 64 MiB; each adaptive helper cache to 32 MiB. Canonical inset values have an additional 128 MiB aggregate cap and the established key/entry policy. Admission reports desired helpers, available memory slots, source estimate and the limiting reason. Oversized job/results drain to the owner evaluator without truncation. Exceeding canonical retention reports FRAME_SLICE_RESOURCE_LIMIT and aborts; resource/integrity/cancellation failures are never treated as recoverable open contours. The actual process working set can exceed the sum of retained estimates because source arrays, render resources, clones, temporary work and garbage collection are separate.

Topology recovery retries the established numerical path first. Unchanged degree-two cycles retain original points and order. Exceptional components use bounded bridge removal and angular face walks on their existing edges; no global weld, arbitrary endpoint chord or whole-model skip is introduced. Valid closed contours remain printable trajectories; unresolved open fragments are diagnostic-only, with bounded group/edge records. Neither complete coverage nor physical printability is certified by recovery.

Model invalidation compares previous and current source geometry/version/world-transform bounds in each printer's rigid frame. Intersection with either old or new volume occupancy clears the result, cancels active work and increments the source generation. This covers entering/leaving, add/delete, hierarchy/instance/generator source changes and undo/redo; edits outside both volumes can retain a cached result. Printer movement retains the existing transform invalidation path.

When Start pushes Finish, or Finish itself changes, Layer position is reset to the complete new Finish layer before draw ranges and shader uniforms are updated. An explicit partial position remains supported when Finish does not change. Reloaded native scenes retain the existing cleared-preview/explicit-re-Slice behavior.

Own development and version-narrative comments are removed with an Acorn token-aware pass across active modules and a literal-aware HTML/CSS pass. Legal notices, directives and vendor source remain protected. The licensed 205,129-byte slicer prefix is exact. Serialized native worker functions are tested in the actual browser. Native hash-XOR-hash dimensional addresses, exact numeric bits, binary metadata and checked gzip/raw envelope semantics are unchanged; no persisted JSON is introduced.

## Remaining work

General clockwise inward spirals and W-long expansion/contraction transitions are unfinished. Preserve source-first material boundaries, outside/hole ordering, exact finite-bank ownership, original source events/seams/axes and the cumulative 0.5-width additional-overlap ceiling. Distinguish commanded flow from display width and nominal nozzle geometry. Every new seam/cap/body intersection is charged; only unchanged ongoing nominal/residual allocation within its original cell is exempt. Intentional thin-region exceptions keep nozzle/ribbon containment, full coverage and physical-print certification false. Unsupported ownership, contact, memory/work-budget or geometry cases retain the established independent paths. Do not extend the bounded verified constant-width neck cases into a claim of general spiral completion.

The pre-existing mixed Morph plus point-animation reload ordering issue remains separate. Its failing fixture and old-code control are retained under qa/results/r178-native-mixed-morph-baseline-control.json. Native 100k/1M/3M/10M storage time/peak-memory benchmarking also remains a later milestone; this release does not claim those scales were tested.

Validation artifacts, failed QA receipts, source hashes, complete-packet parity and measured full Slice-to-paint/process CPU evidence are sealed outside the repository in the r180-production QA archive. Release verification must match main commit, successful Pages head, HTML and all 57 live asset hashes before calling this release published.

## Measured bounded campaign

On the actual 16-logical-thread, 32 GiB Windows/Chrome machine, the heavy-work budget was 15. Complete Slice-to-two-painted-RAF measurements include preparation, worker startup, preview assembly and paint; packet hashing after paint is excluded. Instrumentation records full worker packets and process CPU, so these are correctness-campaign measurements, not an uninstrumented product benchmark.

Preparation overlapped on 14 actual helpers; complete finalization overlapped on up to 14 in the low-poly fixture. All complete packets, raw Float32 angles, canonical reference IDs, path/edge/vertex provenance and public commands matched r179/one/parallel on the two intact scenes. Both complete humans matched one/parallel, preserved closed paths in all 24/27 exceptional layers, and retained the CPU-proven 2943/3305 unchanged normal sections. Final immutable worker replay matched every captured layer on all four scenes after the physical fallback diagnostics correction. Forced oversized replies preserved the complete owner result and reported actual owner/helper caches separately.

Actual inside/enter/leave/add/delete/undo/redo and in-flight cancellation passed. Outside move/delete/undo/redo preserved a nonempty cached Slice. Solid and Lines-Dots range controls passed in both directions; Lines-Dots uses the actual production setter through QA exposure. A 196,608-triangle source completed; simulated one/two-thread and low-memory initialization, actual resource-limit failure with all 15 workers terminated, native source preservation/loader, and real unsaved r179-to-r180 PWA update/offline catalog/texture/native/Slice checks passed. Source intersections and stitching remain in the ordered owner pass; further acceleration of that pass and broad production-size memory benchmarking remain future work.

The preserved failures include test-harness errors (wrong primitive name, readiness predicate, newly assigned object IDs in a geometry comparison, unavailable legacy display button, owner-only forced fallback, and a forced cache cap above the fixture's actual retention). Their corrected runs retain strict geometry checks. The older neck expectation mismatch is retained separately; the actual 11 original-bank/source-angle/minimum-path/contact controls match published r179 packets exactly. No failed receipt was overwritten or presented as a passed full campaign.
