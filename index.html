Open supports native HASH, glTF/GLB, OBJ, STL, PLY, SVG and the documented DXF subset. Save As chooses a format; right-click Download exports interchange files.

Native HASH is the lossless format for editable splines, generators, hierarchy, materials and animation.

Viewport touch: drag one finger to orbit; drag two to pan, or pinch to zoom the camera. Hold then drag to select a rectangle. Hold without dragging and release for the context menu. Double tap: Quad / Single view.

Pinch with a finger in the right panel to zoom the page. To switch from an active viewport gesture to page zoom, lift your fingers and start a new pinch.

Touch: hold for a context menu. In Objects Browser, drag a name or row to move it; drop between rows to reorder, on a row to make a child. Scroll with two fingers, or drag empty space / the left indentation. Release outside the tree to cancel.

Morph modes: Solve adjusts morph values when dragging points; Edit opens pose keys on a separate 0–100 timeline; Modelling disables deformation and edits the reference. Set keys with the animation toolbar. Curves show the selected point's X/Y/Z; drag their tangent handles to adjust motion.
