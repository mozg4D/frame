# Printer fixtures and checks

`node tests/plugin-infrastructure.mjs` runs plugin-local checks in full Chromium headless with hardware WebGPU. Standard and DPR-2 stress suites discover the same checks automatically.

`node plugins/3d-printer/tests/generate-zoo.mjs` creates `tests/scenes/slicer-zoo.hash` and refreshes `slicer-zoo.json`. It contains 27 named cases: rounded taper, acute star, eleven width thresholds around W=2 mm, nested shells/solids, needle and micro-islands, reversed/mixed winding, a missing triangle, duplicate faces, an unwelded 0.04 mm crack and five overhang angles around 45 degrees. The local user-supplied `tests/scenes/test.stl` is included as an incoming-production reference when present. `--without-reference` generates only the compact synthetic cases. No slicing code is involved.

The generated HASH and large original STL remain local/ignored. The recipe and small manifest are versioned. Never alter the original STL to make tests pass. The manifest records its SHA-256 and whether it was present.

The implemented stage and remaining planner specification are in ../AGENTS.md. GPU plane intersections now feed closed section contours with duplicate removal, chain repair, even-odd owner fill, union and bounded simplification. Physical-width offsets and printable trajectory planning remain deferred.

`npm run test:slicer` verifies real Start/Finish UI edits and pixels, native Undo dependencies, exterior/hole colors, nested parity, overlapping/coincident/shared-edge unions, open-chain repair, a dense-circle 0.02W deviation bound, canonical buffer/texture sources, arbitrary printer frames, cancellation and HASH lifetimes. `npm run test:slicer:corpus` checks closed finite output for all 27 fixtures and the unchanged incoming STL. `npm run test:slicer:performance` compares triangle spans with per-layer scanning, measures 4000 layers / 768000 raw intersections, 16384 disconnected closed cubes, multi-buffer processing, memory/readback and CPU/GPU rendering frames. These checks do not certify physical bead placement or swept-strip coverage.
