# 3D Printer

Runtime plugin.js; independent native printer authoring/jobs/resources on shared GPU.

- Local +Y build axis, X/Z [-500,500], Y [0,1000] mm; default pivot/axes (-500,0,-500). Arbitrarily rotated assemblies retain printer-local slicing/warnings.
- Slice directly builds persistent all-layer X/Z GPU depth intervals from evaluated geometry, without polygon repair/union prepass. Connected balanced shells use signed crossings; unbalanced winding falls back to parity. Nested shell clusters alternate within one occurrence; filled material unites across occurrences. Open shells remain ambiguous, never extend to infinity.
- Duplicate events require same shell and bit-identical Float32 depth/plane slopes; never weld thin overlaps with depth tolerance. Orthogonal occupancy excludes ambiguous rays; two ambiguous directions yield no coverage.
- Layer centers: initialHeight/2, then initialHeight+(zeroBasedLayer-0.5)*layerHeight. Target pitch 0.2*Line width; <=2048 samples/axis, <=4194304 total rays. Report increased pitch/resolutionLimited. Limits: 4096 layers, 256 occurrences, 1024 events/ray, 16777216 raw events, further bounded by device. Overflow/cancel/staleness publishes no partial output.
- Finish alone selects coverage/perimeters. First successful Slice initializes last Finish; later builds preserve/clamp it. Start/Layer position remain future-planning authoring. Common assembly motion retains results; relative-frame edits coalesce rebuilds. Geometry/visibility/sampling changes require Slice.
- Selected-layer GPU perimeters offset all filled boundaries by (index+0.5)*Line width, including holes/splits. Discard terminal collapsed loops independently. Two indirect draws show compact white lines/cyan points; retain one layer only. renderKind overlay.
- Exact distance to reconstructed boundary segments drives offsets. Simplification checks every skipped raw vertex; limits retain raw geometry. Max deviation 0.0001..10 mm (default 0.02) bounds simplification against reconstructed offsets, not source/subpixel error. Paths cap at 262144 raw slots/32768 vertices per loop; open/overflow paths suppress the complete draw.
- Finish rebuilds one layer; Perimeters reuses field; Max deviation reuses field/graph. Readback: 56 Slice metadata bytes +48/path update. Geometry/depth/path buffers stay GPU-owned except bounded inspection.
- status exposes grid/ambiguity/duplicates/memory/timings/perimeters. inspect reads <=256 rays (<=4096 intervals), coverage texels or path segments; paths:true accepts raw/boundary. Reject non-displayed coverage/path layer; revalidate source/path revision.
- Line/layer/initial height 0.1..100 mm, Perimeters 1..1000. Overhang angle immediately changes face-warning colors, separate from future deposited-strip support. Preserve Slice/Stop, short progress and native gaps; no Min path length.

No variable-width planner/travel/swept-strip certificate/process control/machine output. Future requirements: clip deposited strips to box, widths normally 0.6W..1.5W, isolated 0.6W..1W features widened to W, ordinary whole paths shorter than 3W omitted, single-loop overlap 0.2W, clockwise spirals/approximately 45-degree planar joins preferred. Boundary target 0.02W needs sharp-corner relaxation; acute-tip 0.1W hold-down needs physical definition. These do not make current output printable.

Checks: npm run test:slicer -- --headless; npm run test:slicer:perimeters -- --headless; npm run test:slicer:corpus -- --headless; npm run test:slicer:performance -- --headless. tests/index.mjs includes independent interval/perimeter oracles, native pixels/history/HASH, paged geometry, ambiguity/cancellation/frames. tests/generate-zoo.mjs reproduces 27 cases; never modify tests/scenes/test.stl. The 4000-layer fixture budgets cold/warm 2/1 s, peak owned GPU <128 MiB, Finish <150 ms, CPU/GPU preview <40 ms; fixture-specific, not universal.
