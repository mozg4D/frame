# 3D Printer

Read `plugin.js` LDI build/cleanup, Finish reconstruction and perimeter stages separately; they have different invalidation keys. Each native printer owns authoring/job/resources on the shared GPU.

- Only last-active eligible printer provides immediate face-angle warning; selecting unrelated geometry/deselecting retains it. Hiding/disabling/deleting it chooses another eligible printer. Warning red blends at 30% opacity over the existing surface and stays beneath Wireframe/Isoparms strokes; completed path colors remain independent. Each printer still owns its helper/job independently. Cold creation selects/publishes owner before coalesced helper/pipeline preparation.
- Local +Y build axis, X/Z [-500,500], Y [0,1000] mm; default pivot/axes (-500,0,-500). The three positive build-box edges use the viewport coordinate-axis colours. Arbitrarily rotated assemblies retain printer-local slicing/warnings.
- Slice directly builds persistent all-layer X/Z GPU depth intervals from evaluated geometry, without polygon repair/union prepass. Connected balanced shells use signed crossings; unbalanced winding falls back to parity. Nested shell clusters alternate within one occurrence; filled material unites across occurrences. Open shells remain ambiguous, never extend to infinity.
- Duplicate events require same shell and bit-identical Float32 depth/plane slopes; never weld thin overlaps with depth tolerance. Orthogonal occupancy excludes ambiguous rays; two ambiguous directions yield no coverage.
- Layer centers: initialHeight/2, then initialHeight+(zeroBasedLayer-0.5)*layerHeight. Target pitch 0.2*Line width; <=2048 samples/axis, <=4194304 total rays. Report increased pitch/resolutionLimited. Limits: 4096 layers, 256 occurrences, 1024 events/ray, 16777216 raw events, further bounded by device. Overflow/cancel/staleness publishes no partial output.
- First successful Slice sets Start=1 and Finish=last. Later builds follow the new last layer when Finish equalled the previous last layer; an explicit limited range is preserved/clamped. Empty builds reset Start/Finish to 1. Running progress/ranges use the current GPU-derived total, never the previous result. Range edits filter cached paths immediately without reslicing. Finish still selects the diagnostic coverage/raw working layer; Layer position remains future-planning authoring. Common assembly motion retains results; source/relative-frame/sampling edits stop a running build and retire completed output immediately. There is no automatic restart; require an explicit Slice. Common assembly motion still retains results. Source, source-ancestor, instance and Solo visibility changes do not affect capture, running Slice or completed paths; only the printer's own effective visibility hides its result. Calculation-disabled objects remain excluded.
- Capture/signatures use printer-local BUILD_BOUNDS; wholly outside occurrences are excluded conservatively before submission. GPU bounds clip triangles to the X/Z build footprint before measuring height. Capture and every signature use includeHidden:true, from job admission through publication, status, drawing, path edits and inspection. Preserve native structural consumption: hidden Boolean/generator outputs and clone occurrences participate without reintroducing their consumed operands or prototypes. Source geometry, relative frames, deletion, sampling, document and device still invalidate completed results. No retained polygon snapshot or visibility mutation is needed.
- Current output is the section perimeter itself, including holes, with zero offset. The perimeter kernel links exact reconstructed LDI crossings and recovered corners directly, then simplifies within Max deviation; it does not interpolate the zero isocontour of a sampled distance field. Perimeters is temporarily hidden/ignored and one boundary is generated per loop. Offset outline/bead planning is deferred. Preview defaults to camera-facing butt-ended bead rectangles: one instanced triangle-strip draw reads compact paths and layer indices. Identical sections use four vertices. Changing sections use two extra pairs to limit the join to one line width from each end and keep straight wall spans stable. Use the true oval support point, including depth, from Line width, the actual first/subsequent layer height and the printer affine frame. A pure screen-plane extent can exceed the physical layer height at oblique views; do not restore it. Join adjacent endpoints with a bounded horizontal miter and the larger valid vertical support, never exceeding half the layer height; end-on neighbours must not halve the visible strip height. The muted cool grey centre is RGB (.50,.54,.55); the transverse rim smoothly darkens from 40% of half-width to RGB (.10,.13,.14). Average the exposed rim across the pixel footprint and limit the overlap contribution to the spacing between projected layer centres. No end-cap darkening or round caps. renderKind overlay. Only compact segments/layer indices persist for all layers (<=4194304 segments); one reusable range boundary/graph is retired after publication, while the interactive Finish field remains cached. No all-layer distance volume or CPU polygon mirror.
- Temporary Polyline action is off by default and per printer; it is runtime presentation state, not HASH/Undo authoring. On restores the two white-line/cyan-point range draws. Toggling retains paths, layer range, source signature and build identity. Rectangles write/test ordinary scene depth in renderStage opaque, with nearer layers submitted first according to view-space build direction; foreground scene geometry occludes them. Polylines and points also test scene depth. Helpers and face warnings retain their overlay stage; no separate preview depth target is allocated. One 16-byte draw-range uniform replaces CPU quad expansion.
- After path emission, GPU neighbours/remap reuse label jump slots 0/2 to produce dense layer-local metadata {id,next,previous,loop}; roots 1/3 and simplification flags stay intact for deviation-only rebuilds. The 32-byte segment record is unchanged. Packing repeats these indices per layer; rendering addresses neighbours relative to segmentIndex-id, with no extra per-segment buffer or CPU adjacency. Bounded inspection still reports perimeter=1 for section output.
- Compare exact interval bits to reuse identical adjacent sections; certified vertical source planes use height-independent depth evaluation, never a geometric equality tolerance. Range scratch visits the canonical cell for each LDI endpoint, emits the raw boundary and records its connections in one pass. Publish a complete replacement after source/owner checks; stale/cancel/overflow never publishes a partial range.
- Each loop starts simplification at its lexicographically lowest point with a cell-edge tie break. Exact monotone axis-aligned spans can skip intermediate distance checks because the maximal segment distance occurs at an endpoint. Max deviation 0.0001..10 mm (default 0.02) bounds simplification against the reconstructed boundary. Limits retain raw geometry. Paths cap at 262144 raw slots/32768 vertices per loop; open/overflow paths suppress the complete draw.
- Stop releases unpublished resources at next async checkpoint; Undo deletion restores authoring, never resurrects retired GPU job. A restart is a new valid job.
- Finish rebuilds one diagnostic layer; Max deviation reuses its boundary/graph. Deviation changes also rebuild the complete compact range asynchronously, retaining the last complete display until replacement. Readback: 56 LDI metadata bytes, 4 bytes/layer for section identity and 48 bytes/path build. Geometry/depth/path buffers stay GPU-owned except bounded inspection.
- status exposes sourceOccurrences/grid/ambiguity/duplicates/memory/timings/perimeters and full preview state/range/segments/completed sections. inspect reads <=256 rays (<=4096 intervals), coverage texels or path segments; paths:true with explicit layer reads the actual compact draw buffer for that displayed layer. Default/raw/boundary paths and coverage inspect Finish. Reject non-displayed compact/coverage layers; revalidate source/path revision.
- During Slice, status.completed/status.total count ready layers and total layers, not unique sections or LDI phases. Total is zero until bounds determine it; Attributes shows `0 / …` then `ready / total`. Reused adjacent sections advance by their actual layer count. Coalesce progress refreshes through RAF, cancel pending refresh on retirement/completion, and clear the counter after completion/cancel/failure. Preserve enabled Stop while running.
- Native navigation queries the displayed compact segments on GPU, using the current camera, printer world frame and layer range; read back one 16-byte depth result only. Clip to the camera interval and use perspective-correct segment interpolation within eight CSS pixels or the displayed rectangle half-width, whichever is larger. Rectangle queries intersect the same butt-ended strip triangles used for drawing, including the straight centre on changing sections. Prefer exact triangle hits over the eight-pixel centreline fallback; the winner uses one private quality bit decoded before returning positive depth. Respect viewport.isVisible, serialize/coalesce queries, and reject changed camera/view/frame/result/range/source after awaits. Orbit and cursor-anchored zoom work while source geometry is hidden; do not copy all polylines to CPU or pick the build-box helper instead.
- Line/layer/initial height 0.1..100 mm, Perimeters 1..1000. Overhang angle immediately changes face-warning colors, separate from future deposited-strip support. Preserve Slice/Stop and native gaps; progress is left-aligned and empty when idle. Polyline is the final Attributes row. No Min path length.

## Future bead/toolpath contract

The current paths and bead rectangles are sampled preview only: no variable-width bead planner/travel/swept-strip certificate/process control/machine output. Preserve these accepted requirements when that stage is implemented:

- Use printer-local geometry and original vector boundaries, clip filled regions then verify whole deposited strips inside build envelope. A fine full-bed/full-volume SDF is too large for intended large-format jobs; sparse distance acceleration cannot replace vector topology/coverage checks.
- Jointly distribute bead count/width, normally 0.6W..1.5W: width 1.5W -> one bead, 1.6W -> two 0.8W beads. Isolated available 0.6W..1W feature widens intentionally to W; this exception does not certify original-surface accuracy. Smooth count transitions; distribute residual among final two or more perimeters.
- Omit an ordinary whole extrusion trajectory shorter than 3W, not every short curve segment. Prefer continuous clockwise perimeter spirals viewed from +Y toward bed, approximately 45-degree planar connectors, low travel/path count; no continuous-Z vase interpretation or global-optimum promise. Single-loop start/finish overlap 0.2W.
- Normal boundary target 0.02W includes neighboring-strip joins; sharp bends may relax to avoid excessive segments, but exact policy needs definition. At corners sharper than 45 degrees expand up to 1.5W against boundaries, taper to W toward tip until available width 0.6W; return uses requested 0.1W pressing over 1W travel before widening. This deliberate corner exception still needs physical motion/extrusion meaning and print validation, not invented gap filling.
- Intended constant volumetric flow varies travel speed with bead width; geometry comes first. Deposited support compares strips to previous layer in printer coordinates: lateral growth layerHeight*tan(overhangAngle), bed supports first layer. Face-angle warning is a different immediate pre-slice diagnostic and must not require reslice for colour changes.
- Billboard rendering does not certify the actual swept bead. Validate physical swept geometry independently of its presentation; never one object/CPU quad array per segment or all-layer fine-grid allocation.
- Corpus/acceptance must cover width thresholds, corners, narrow walls, nested shells, bridges/holes/islands, winding/cracks, arbitrary frames, stale/cancel and coverage/void/double deposition as well as latency/memory. Existing LDI/perimeter checks do not establish those guarantees.
