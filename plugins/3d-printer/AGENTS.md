# 3D Printer

Read `plugin.js` LDI build/cleanup, Finish reconstruction and perimeter stages separately; they have different invalidation keys. Each native printer owns authoring/job/resources on the shared GPU.

- Only last-active eligible printer provides immediate face-angle warning; selecting unrelated geometry/deselecting retains it. Hiding/disabling/deleting it chooses another eligible printer. Warning red blends at 30% opacity over the existing surface and stays beneath Wireframe/Isoparms strokes; completed path colors remain independent. Each printer still owns its helper/job independently. Cold creation selects/publishes owner before coalesced helper/pipeline preparation.
- Local +Y build axis, X/Z [-500,500], Y [0,1000] mm; default pivot/axes (-500,0,-500). Arbitrarily rotated assemblies retain printer-local slicing/warnings.
- Slice directly builds persistent all-layer X/Z GPU depth intervals from evaluated geometry, without polygon repair/union prepass. Connected balanced shells use signed crossings; unbalanced winding falls back to parity. Nested shell clusters alternate within one occurrence; filled material unites across occurrences. Open shells remain ambiguous, never extend to infinity.
- Duplicate events require same shell and bit-identical Float32 depth/plane slopes; never weld thin overlaps with depth tolerance. Orthogonal occupancy excludes ambiguous rays; two ambiguous directions yield no coverage.
- Layer centers: initialHeight/2, then initialHeight+(zeroBasedLayer-0.5)*layerHeight. Target pitch 0.2*Line width; <=2048 samples/axis, <=4194304 total rays. Report increased pitch/resolutionLimited. Limits: 4096 layers, 256 occurrences, 1024 events/ray, 16777216 raw events, further bounded by device. Overflow/cancel/staleness publishes no partial output.
- First successful Slice sets Start=1 and Finish=last, displaying every layer; later builds preserve/clamp the authored Start–Finish range. Range edits filter cached paths immediately without reslicing. Finish still selects the diagnostic coverage/raw working layer; Layer position remains future-planning authoring. Common assembly motion retains results; relative-frame edits coalesce rebuilds. Geometry/sampling changes require Slice. Completed paths survive source, source-ancestor, instance and Solo visibility changes; only the printer's own effective visibility hides them. Running Slice still rejects visibility changes, and an explicit new Slice uses currently visible geometry.
- A running job validates the visible capture signature. At successful publication it records the visibility-independent signature (`scene.signature(...,{includeHidden:true})`) for later status, drawing, path edits and inspection. Source geometry, relative frames, deletion, sampling, document and device still invalidate completed results. No retained polygon snapshot or visibility mutation is needed.
- GPU perimeters offset all filled boundaries by (index+0.5)*Line width, including holes/splits. Discard terminal collapsed loops independently. Two range draws show compact white lines/cyan points at every displayed layer's actual height. renderKind overlay. Only compact segments/layer indices persist for all layers (<=4194304 segments); one reusable range field/graph is retired after publication, while the interactive Finish field remains cached. No all-layer distance volume or CPU polygon mirror.
- Compare exact interval bits to reuse identical adjacent sections; certified vertical source planes use height-independent depth evaluation, never a geometric equality tolerance. Range scratch seeds only cells crossed by LDI endpoints, and the boundary pyramid certifies empty tiles outside the requested offset band. Publish a complete replacement after source/owner checks; stale/cancel/overflow never publishes a partial range.
- Exact distance to reconstructed boundary segments drives offsets. Simplification checks every skipped raw vertex; limits retain raw geometry. Max deviation 0.0001..10 mm (default 0.02) bounds simplification against reconstructed offsets, not source/subpixel error. Paths cap at 262144 raw slots/32768 vertices per loop; open/overflow paths suppress the complete draw.
- Stop releases unpublished resources at next async checkpoint; Undo deletion restores authoring, never resurrects retired GPU job. A restart is a new valid job.
- Finish rebuilds one diagnostic layer; Perimeters reuses its field; Max deviation reuses its field/graph. Count/deviation changes also rebuild the complete compact range asynchronously, retaining the last complete display until replacement. Readback: 56 LDI metadata bytes, 4 bytes/layer for section identity and 48 bytes/path build. Geometry/depth/path buffers stay GPU-owned except bounded inspection.
- status exposes grid/ambiguity/duplicates/memory/timings/perimeters and full preview state/range/segments/completed sections. inspect reads <=256 rays (<=4096 intervals), coverage texels or path segments; paths:true with explicit layer reads the actual compact draw buffer for that displayed layer. Default/raw/boundary paths and coverage inspect Finish. Reject non-displayed compact/coverage layers; revalidate source/path revision.
- During Slice, status.completed/status.total count ready layers and total layers, not unique sections or LDI phases. Total is zero until bounds determine it; Attributes shows `0 / …` then `ready / total`. Reused adjacent sections advance by their actual layer count. Coalesce progress refreshes through RAF, cancel pending refresh on retirement/completion, and clear the counter after completion/cancel/failure. Preserve enabled Stop while running.
- Native navigation queries the displayed compact segments on GPU, using the current camera, printer world frame and layer range; read back one 16-byte depth result only. Clip to the camera interval and use perspective-correct segment interpolation within eight CSS pixels. Respect viewport.isVisible, serialize/coalesce queries, and reject changed camera/view/frame/result/range/source after awaits. Orbit and cursor-anchored zoom work while source geometry is hidden; do not copy all polylines to CPU or pick the build-box helper instead.
- Line/layer/initial height 0.1..100 mm, Perimeters 1..1000. Overhang angle immediately changes face-warning colors, separate from future deposited-strip support. Preserve Slice/Stop and native gaps; the area left of Slice is empty when idle. No Min path length.

## Future bead/toolpath contract

The current polylines are sampled preview only: no variable-width bead planner/travel/swept-strip certificate/process control/machine output. Preserve these accepted requirements when that stage is implemented:

- Use printer-local geometry and original vector boundaries, clip filled regions then verify whole deposited strips inside build envelope. A fine full-bed/full-volume SDF is too large for intended large-format jobs; sparse distance acceleration cannot replace vector topology/coverage checks.
- Jointly distribute bead count/width, normally 0.6W..1.5W: width 1.5W -> one bead, 1.6W -> two 0.8W beads. Isolated available 0.6W..1W feature widens intentionally to W; this exception does not certify original-surface accuracy. Smooth count transitions; distribute residual among final two or more perimeters.
- Omit an ordinary whole extrusion trajectory shorter than 3W, not every short curve segment. Prefer continuous clockwise perimeter spirals viewed from +Y toward bed, approximately 45-degree planar connectors, low travel/path count; no continuous-Z vase interpretation or global-optimum promise. Single-loop start/finish overlap 0.2W.
- Normal boundary target 0.02W includes neighboring-strip joins; sharp bends may relax to avoid excessive segments, but exact policy needs definition. At corners sharper than 45 degrees expand up to 1.5W against boundaries, taper to W toward tip until available width 0.6W; return uses requested 0.1W pressing over 1W travel before widening. This deliberate corner exception still needs physical motion/extrusion meaning and print validation, not invented gap filling.
- Intended constant volumetric flow varies travel speed with bead width; geometry comes first. Deposited support compares strips to previous layer in printer coordinates: lateral growth layerHeight*tan(overhangAngle), bed supports first layer. Face-angle warning is a different immediate pre-slice diagnostic and must not require reslice for colour changes.
- Future GPU strip drawing uses compact buffers/butt-ended camera-facing rectangles without round caps, bright broad interior/dark edge gradient. Validate actual swept geometry independently of its presentation. Never one object/CPU quad array per segment or all-layer fine-grid allocation.
- Corpus/acceptance must cover width thresholds, corners, narrow walls, nested shells, bridges/holes/islands, winding/cracks, arbitrary frames, stale/cancel and coverage/void/double deposition as well as latency/memory. Existing LDI/perimeter checks do not establish those guarantees.
