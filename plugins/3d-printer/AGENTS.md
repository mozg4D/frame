# 3D Printer

Read `plugin.js` LDI build/cleanup, Finish reconstruction and perimeter stages separately; they have different invalidation keys. Each native printer owns authoring/job/resources on the shared GPU.

- Only last-active eligible printer provides immediate face-angle warning; selecting unrelated geometry/deselecting retains it. Hiding/disabling/deleting it chooses another eligible printer. Each printer still owns its helper/job independently. Cold creation selects/publishes owner before coalesced helper/pipeline preparation.
- Local +Y build axis, X/Z [-500,500], Y [0,1000] mm; default pivot/axes (-500,0,-500). Arbitrarily rotated assemblies retain printer-local slicing/warnings.
- Slice directly builds persistent all-layer X/Z GPU depth intervals from evaluated geometry, without polygon repair/union prepass. Connected balanced shells use signed crossings; unbalanced winding falls back to parity. Nested shell clusters alternate within one occurrence; filled material unites across occurrences. Open shells remain ambiguous, never extend to infinity.
- Duplicate events require same shell and bit-identical Float32 depth/plane slopes; never weld thin overlaps with depth tolerance. Orthogonal occupancy excludes ambiguous rays; two ambiguous directions yield no coverage.
- Layer centers: initialHeight/2, then initialHeight+(zeroBasedLayer-0.5)*layerHeight. Target pitch 0.2*Line width; <=2048 samples/axis, <=4194304 total rays. Report increased pitch/resolutionLimited. Limits: 4096 layers, 256 occurrences, 1024 events/ray, 16777216 raw events, further bounded by device. Overflow/cancel/staleness publishes no partial output.
- Finish alone selects coverage/perimeters. First successful Slice initializes last Finish; later builds preserve/clamp it. Start/Layer position remain future-planning authoring. Common assembly motion retains results; relative-frame edits coalesce rebuilds. Geometry/visibility/sampling changes require Slice.
- Selected-layer GPU perimeters offset all filled boundaries by (index+0.5)*Line width, including holes/splits. Discard terminal collapsed loops independently. Two indirect draws show compact white lines/cyan points; retain one layer only. renderKind overlay.
- Exact distance to reconstructed boundary segments drives offsets. Simplification checks every skipped raw vertex; limits retain raw geometry. Max deviation 0.0001..10 mm (default 0.02) bounds simplification against reconstructed offsets, not source/subpixel error. Paths cap at 262144 raw slots/32768 vertices per loop; open/overflow paths suppress the complete draw.
- Stop releases unpublished resources at next async checkpoint; Undo deletion restores authoring, never resurrects retired GPU job. A restart is a new valid job.
- Finish rebuilds one layer; Perimeters reuses field; Max deviation reuses field/graph. Readback: 56 Slice metadata bytes +48/path update. Geometry/depth/path buffers stay GPU-owned except bounded inspection.
- status exposes grid/ambiguity/duplicates/memory/timings/perimeters. inspect reads <=256 rays (<=4096 intervals), coverage texels or path segments; paths:true accepts raw/boundary. Reject non-displayed coverage/path layer; revalidate source/path revision.
- Line/layer/initial height 0.1..100 mm, Perimeters 1..1000. Overhang angle immediately changes face-warning colors, separate from future deposited-strip support. Preserve Slice/Stop, short progress and native gaps; no Min path length.

## Future bead/toolpath contract

The current polylines are sampled preview only: no variable-width bead planner/travel/swept-strip certificate/process control/machine output. Preserve these accepted requirements when that stage is implemented:

- Use printer-local geometry and original vector boundaries, clip filled regions then verify whole deposited strips inside build envelope. A fine full-bed/full-volume SDF is too large for intended large-format jobs; sparse distance acceleration cannot replace vector topology/coverage checks.
- Jointly distribute bead count/width, normally 0.6W..1.5W: width 1.5W -> one bead, 1.6W -> two 0.8W beads. Isolated available 0.6W..1W feature widens intentionally to W; this exception does not certify original-surface accuracy. Smooth count transitions; distribute residual among final two or more perimeters.
- Omit an ordinary whole extrusion trajectory shorter than 3W, not every short curve segment. Prefer continuous clockwise perimeter spirals viewed from +Y toward bed, approximately 45-degree planar connectors, low travel/path count; no continuous-Z vase interpretation or global-optimum promise. Single-loop start/finish overlap 0.2W.
- Normal boundary target 0.02W includes neighboring-strip joins; sharp bends may relax to avoid excessive segments, but exact policy needs definition. At corners sharper than 45 degrees expand up to 1.5W against boundaries, taper to W toward tip until available width 0.6W; return uses requested 0.1W pressing over 1W travel before widening. This deliberate corner exception still needs physical motion/extrusion meaning and print validation, not invented gap filling.
- Intended constant volumetric flow varies travel speed with bead width; geometry comes first. Deposited support compares strips to previous layer in printer coordinates: lateral growth layerHeight*tan(overhangAngle), bed supports first layer. Face-angle warning is a different immediate pre-slice diagnostic and must not require reslice for colour changes.
- Future GPU strip drawing uses compact buffers/butt-ended camera-facing rectangles without round caps, bright broad interior/dark edge gradient. Validate actual swept geometry independently of its presentation. Never one object/CPU quad array per segment or all-layer fine-grid allocation.
- Corpus/acceptance must cover width thresholds, corners, narrow walls, nested shells, bridges/holes/islands, winding/cracks, arbitrary frames, stale/cancel and coverage/void/double deposition as well as latency/memory. Existing LDI/perimeter checks do not establish those guarantees.
