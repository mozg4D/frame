# Mill

Runtime one plugin.js; evaluated buffer/texture geometry and shared GPU. No Printer runtime dependency or CPU triangle mirror.

## Physical/program contract

- Stock/Protected are global inherited native tags independent of CNC parenting. Native hierarchy is unrestricted; unsupported skew/reflection/degeneracy/incompatible axes are red/ignored. Green skips computation while retaining helpers/descendants. Cutters extend infinitely upward; Step Down is a pass maximum, no holder/flute/stick-out model.
- Slice plans full fixed-axis CAM in native preorder from actual preceding stock/cuts/position. Canonical material is original GPU source plus continuous analytic sweeps. Bounded derived CPU fields may guide planning; display LOD/sampling/numeric padding/requested Tolerance remain distinct.
- Flat/Ball/V share analytic models across collision/subtraction/accessibility/display. Quantize endpoints before full-sweep checks. Verify external stock, Safe Dist along entire rapids, Feed/vertical Plunge, signed contact, cumulative ramp XY, tool changes and final home.
- Full planning/replay/export success alone publishes N/Progress=N. No partial result on failure/cancel/staleness. Random/backward Progress replays immutable source/checkpoints; later operations never reset stock. Common rigid assembly motion may retain output; source/relative-frame/settings/device changes retire it. HASH stores authoring only.
- Preserve inherited materials/masks/UVs through native fragment filtering; cut/fallback presentation is derived. Time is exported feed/dwell lower bound; rapid/acceleration/manual pauses remain unknown.
- LinuxCNC stream establishes G21 G90 G17 G94 G40 G80 G61 G54 and M5 S0. Root is configured G54 coordinates; first tool installed, no G92, all tools preset to the same calibrated tip offset. Start block once; tool-change requires stopped spindle plus M0; finish verifies home then M5/M30.
- Custom accepted state: finite absolute metric G0/G1, G4 P, listed startup modes, F/S, M0/M1/M3/M4/M5/M7/M8/M9 and comments/line numbers. Custom G1 positioning is clear-air only; every motion uses common verifier. Reject relative/inch/arcs/offsets/G28/G53/G92/G43/G64/M6/macros/custom termination. Quantize S to 0.001 RPM, P to 0.000001 s before recording; reject positive values lost to precision.

## Certificates and limits

- Independently validate native GPU interiors: exact welding, closed incidence, intersections/shell relations and guarded affine mapping. Uncertain Float32 predicates use bounded GPU dyadic resolution, not zero. Closed-source winding must not change volume. Open/nonmanifold/ambiguous/capacity failures keep explicit XYZ-policy fallback, never a certificate.
- Preserve triangle-boundary cells even if XYZ rays miss thin material. Interior validity/cell completeness/evaluator error/finished-surface accuracy are separate claims. Share proofs across occurrences without CPU triangle readback.
- Source envelopes come from shared evaluator/capture. Tight bounds require matched closed parameter boundaries, native interior validation and stable shell relations. Multiple components require guarded separation >2*local error; otherwise retain entire enclosing-domain band. Curved planar fills need exact coplanarity/simple disjoint cubics/native triangulation coverage and orientation, not sampled simplicity.
- General cells use actual coefficient/ribbon enclosures. Full-domain fallback may be object-wide: never cap it to force Tolerance; retain coarseReasons/coarseEnvelopes. Morph/point-animation attestations bind geometry revision (version minus frameRevision); clear before evaluation, restore only on successful publication. Rebuild unattested cached HASH surfaces. Cache proof metadata, not generated triangles.
- Propagate possible source-band material through collision/subtraction/whole-part proof; adding scalar error afterward is insufficient. nativeSurfaceCertified never implies finishedSurfaceCertified.
- Desired material is Target union (original Stock intersect Protected), including outside boxes and Target absent from initial Stock. Floating Protected is an obstacle, not required workpiece. Proved missing Target rejects with MISSING_TARGET; proved gouge rejects; remaining proved reachable excess rejects with UNRESOLVED_STOCK.
- Both material/boundary-distance directions need conservative coverage. Opposite membership witnesses bound real crossings; cell diagonals do not certify distance. Unknown/limited leaves remain explicit, possibly refining to Tolerance/64.
- Adaptive audits commit whole blocks transactionally; cancellation preserves partition/sums. Continuation uses frozen operation/final prefix at any Progress and may invalidate immutable programs, never rewrite published motion. Operation/part queues share 32 MiB/job and 65536 regions/audit; retire all owned queries/frontiers.
- Accessibility needs complete contacting XY pose covers, guarded highest-tip bounds and proved interior witnesses across every supported setup. Missing witnesses/budgets never mean inaccessible. Search off-centre after blocked centre; positive poses cover the entire excess box and pass full-domain collision checks.
- Witness cap 8192; per-region 2048 pose boxes/50 ms, audit pass 64 queries/500 ms (in-flight work can extend limits). Failed pose caches <=4096 keys/proof, charged 256 bytes/key to shared witness budget; frozen source/prefix owns them, stock corrections reset them. Corrections follow setup preorder/tool changes and return home once.

Discover plugins.describe for schemas. geometryOnly:true is sampled diagnostic mode, not completed CAM. inspect reports root-physical conservative cells/interior model/source flags. audit scope part resumes final-prefix proof; default scope is operation. Indexed/re-fixtured machining, finite holders and unsupported/limited source relations remain outside the model.

Checks: node plugins/mill/tests/run.mjs --headless; npm run test:mill:performance -- --headless. tests/index.mjs discovers independent cutter/sweep/G-code replay/source-envelope/whole-part/residual/accessibility/history/budget checks. The 100M-triangle benchmark measures residency/presentation, not full CAM throughput.
