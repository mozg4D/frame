# Mill

Mill plans a fixed-axis three-axis job on Frame's shared WebGPU device. Default Slice builds sequential roughing, contours and nonplanar finishing, verifies continuous cutter sweeps, validates source interiors where supported, audits remaining 3D material, replays material removal and publishes one immutable stream for display, Progress, time and LinuxCNC G-code. A completed job reports complete and machiningReady:true: a program in the documented model. Whole-part native solid and surface-distance verification is bounded and explicit. General authoring/evaluator enclosures and bounded full-pose accessibility proofs are implemented below. Their finite proof, precision and resource limits remain explicit; see TODO.md for the completed implementation checklist and model boundaries.

## Native scene and coordinates

CNC is an ordinary plugin object. Its local box is X/Y [-50,50], Z [-100,0]; its default pivot/home is the upper near-left corner (-50,-50,0). Native transforms, hierarchy, enabled/visible state, Undo/Redo and HASH apply normally. CNC can live beneath a part/assembly. Positive orthogonal scale changes physical box dimensions; cutter, feed, tolerance and clearance parameters remain physical millimetres.

Stock and Protected are ordinary inherited scene tags, independent of CNC parenting. Stock supplies material; Protected supplies forbidden geometry. A dual-tagged occurrence participates in both. Evaluated geometry with neither tag is Target. Non-CNC children of CNC have no implicit protected role. A root collects CNC descendants in actual Scene Tree preorder through intervening ordinary nodes. Green skips only that operation without hiding helpers/descendants. A disabled root still supplies coordinates and lifecycle text for enabled descendants.

Arbitrary rigid world orientation/translation and positive nonuniform orthogonal scale are supported. Skew, reflection, degeneracy and a directed child tool axis differing from the root by more than 1e-9 in unit-vector distance are red/ignored. Native editing is unrestricted. In-plane child rotations are supported; indexed/re-fixtured jobs need a different physical model.

## Tools and planning

Flat, Ball and V are analytic radial epigraphs extending upward indefinitely. V Angle is the included angle. No holder/flute/stick-out parameters exist. Step Down is a maximum pass depth, not cutter length. Signed Spindle selects M3/M4; cutting requires nonzero RPM.

GPU triangle clipping builds conservative top envelopes for initial/current Stock, Target and Protected. Thin features and degenerate projected edges survive between ray centers. Source triangles are never mirrored to CPU. Bounded field tiles/max-min pyramids may be read for planning. Appended generated sweeps update these derived fields in Float64 using the same analytic cutter functions. Evicted/new tiles reconstruct preceding history from native GPU source and sweeps. Actual XYZ interval subtraction and retained virtual stock remain GPU-owned.

Roughing distributes depth/row spacing evenly within Step Down/Step Over. Ball/V depth and row budgets account for their profiles. Configuration-space bands generate clearing and obstacle/island contours. Finishing refines surface heights and full swept chords; row spacing is additionally limited by Tolerance/scallop. Remaining reachable stock samples trigger up to three local refinement passes; unresolved samples fail publication. Accessibility-limited residual candidates remain explicit. This finite top inspection does not prove inaccessibility; the independent full-part pose cover below supplies that separate certificate.

Current contact side and signed RPM choose climb direction for one-sided cuts. Full-slot/conservative/ambiguous contact is labelled explicitly. Continuation is preferred; otherwise entries use cumulative-XY ramps, validated helices or bounded pecks, with constant-depth cleanup. Endpoints are quantized before verification. Feed is capped by Feed and the actual absolute vertical Plunge component, including rotated operation frames.

Transitions test direct Safe Dist sweeps, then find the minimum verified lift in the available upper plane. A blocked straight line can use a bounded A* XY visibility graph around conservative source bounds. Every edge checks the full continuous cutter against current material and Protected. The upper plane and destination descent are validated, never assumed safe. Controlled feed retracts use the already-cleared pose; G0 cannot inherit that exemption.

Actual root-physical tool position and material history carry across operations. Same-tool operations add no tool change/home return. Different tools retract safely, verify both tool envelopes, stop, execute a mandatory manual pause block, install the new tool and restart signed RPM. The generated final lifecycle returns to root home once, stops and ends the program.

## Stock, tolerance and limits

Canonical stock is borrowed original GPU source plus ordered analytic cuts. Shared Stock/Protected include all geometry outside every CNC box. Each operation freezes stock after preceding operations, forbids removal outside its physical box and advances the shared revision only for actual cut events. It never restarts from virgin stock.

Sampled XYZ import independently embeds Printer's geometric crossing cleanup, connected shells, interpenetrating-shell union, nested even-odd and occurrence union policy. All axes share labels. Stored normals are ignored. Raw geometry/events/depths remain GPU-owned. A nonempty import reads 56 metadata bytes, plus optional retained GPU shell labels. Subtraction uses analytic linear sweeps in 32-motion exact-allocation GPU batches, reading 16 allocation bytes per batch. An inner numerical envelope prevents rounding from removing unverified extra material.

Full CAM also performs an independent source-interior validation on native buffer or texture geometry. Exact Float32 position keys weld geometric seams, normalizing signed zero without epsilon welding. GPU edge incidence proves closure; geometric pair checks reject intersections beyond a shared vertex or edge. Closed unoriented surface complexes use parity independently of authored face order. Strictly disjoint shells are classified for nesting; proved transverse crossings or inside/outside boundary witnesses join interpenetrating shells. Each resulting cluster uses union, clusters use nested parity within an occurrence, and separate occurrences use union. Unresolved contacts receive no certificate. No source triangles are read to CPU or retained as a replacement scene.

Orientation predicates use a guarded Float32 filter. Uncertain signs enter a bounded GPU query cache and are resolved by exact integer dyadic arithmetic over canonical Float32 bits, including subnormals. The resolver is a separate compute stage; an uncertain sign is never treated as geometric zero. Validation is bounded to 4096 triangles, 262144 vertices and 128 components per geometry, 67108864 conservative predicate-work units per job, and 64 MiB of retained proof data. Exact-query workspaces hold 65536 records, at most 128 probes and 16 refinement rounds; pair work runs in bounded batches. Exceeding a limit or finding an open/nonmanifold edge, degenerate face, self-intersection or unresolved shell contact leaves the source uncertified with a reason and representative object hash. Pipeline waits and compute batches recheck cancellation/source identity. Geometry proofs are shared by native occurrences and operation frames, while source geometry stays borrowed.

The full-domain dense snapshot is a sampled display LOD, limited in extent to approximately 256 cells per axis independently of machining Tolerance. Coarsening is explicitly labelled. Fine lazy 32-cubed XYZ tiles use Tolerance/(8 sqrt(3)), inherit canonical shell labels, reconstruct source plus selected cuts and use a bounded 64 MiB/128-tile LRU. Their sampleCellDiagonal is not a certified source-error bound.

A separate lazy 16-cubed volume grid uses the same fine pitch and its own 64 MiB/128-tile LRU. GPU triangle-to-cell clipping covers every source surface cell, including thin components missed by all XYZ rays. For validated sources, exact half-open ray membership is evaluated at a point only after whole-cell boundary exclusion. Guarded inverse/forward affine mapping proves that the tested native point belongs to the requested physical cell. Membership and shell grouping bypass XYZ cleanup labels. Boundary cells and unresolved mapping/predicate queries stay conservative. Unsupported sources retain the explicitly labelled XYZ-policy path. Continuous Flat/Ball/V sweeps produce inner removal and outer touch bounds. Full coverage of convex cell bottoms or complete sub-rectangles proves removal by a sweep or union; unrelated cut corner samples cannot erase an interior hole. Concurrent queries share owned tiles; superseded Progress and retired jobs cannot publish stale cells.

status.source reports validation, bounded issue details, work limits, timings and actual retained proof bytes; accuracy.sourceInteriorCertified reports the validated input-shell model. inspect volume reports its local interiorCertified model and classificationComplete, which excludes additional unknown membership flags while retaining conservative triangle-boundary cells. Source-distance and finished-part flags also require the approximation contracts below; input-shell validation alone cannot set them. This distinction also applies when the source certificate succeeds but numerical cell mapping remains uncertain.

After residual refinement, each operation runs an adaptive audit over the intersection of its Stock bounds and physical operation box. It queries Stock/Target/Protected volume cells, subdividing uncertain regions toward a cell diagonal of Tolerance/4. Whole-cell distance bounds to reference cells can establish one-sided remaining-material proximity. source/remaining expose inner/outer volumes; outsideTolerance and gouge distinguish confirmed lower bounds from possible upper bounds. Possible bounds include confirmed material and, for an incomplete audit, all unvisited volume. Confirmed removal inside desired material fails with VOLUME_GOUGE. This audit includes buried material, but does not certify reverse deviation or initially missing Target material, arbitrary source interiors, or residual inaccessibility. An operation excess audit never sets the finished-surface flag, even when excessWithinTolerance is true.

The audit is bounded to 131072 processed cells, 256 blocks and 5000 ms, checked between bounded blocks/cell work; the final block may extend a limit. complete means that traversal finished. A limited audit reports limit, unvisitedVolume and possible excess instead of a complete certificate; a CAM program may still complete under the existing sweep/field verifier. It reports up to 32 unresolved regions for inspection, without labelling them inaccessible. accuracy.volumeAuditComplete aggregates traversal completion, independently of sourceAccuracyCertified and finishedSurfaceCertified. Continuation uses audit {operation?,maxCells?,maxBlocks?,maxMs?}. It starts bounded background work; poll status.audit.running. Each pass has its own budgets with maxima equal to the initial pass. Omitting operation selects the first unfinished operation; a completed selection is a no-op. The saved Float64 region frontier is bounded to 65536 regions per operation and 32 MiB of packed queues per job. Queue allocation failure raises AUDIT_CAPACITY. Only complete blocks commit counters and child regions, so cancellation/failure never double-counts work. Last-run and cumulative counters, pendingRegions, retainedQueueBytes, resumable and unvisitedVolume remain explicit. Finishing a traversal frees its queue. Checkpoints are derived and are not saved in HASH.

Planning cell diagonal is at most Tolerance/8, further refined for small/sharp tools. Path allowance is Tolerance/8; adaptive height variation and shape scallop each use Tolerance/8, finishing rows at most Tolerance/2, and controller quantum at most Tolerance/64. Source/sweep Float32 envelopes have explicit guards and fail NUMERIC_LIMIT when exceeded. These algorithmic budgets are not a certificate for malformed interiors, missed sub-sample topology or every finished surface. Unknown authoring families keep sourceAccuracyCertified false. Machining precision is never silently weakened to fit capacity.

Actual source surfaces retain native assigned/inherited materials, polygon masks and UVs. A generated-motion BVH filters removed fragments before native shading. Compact GPU cut-endpoint patches show new surfaces at display resolution; paths and a visual cutter share the same stream. Finite display height does not limit the infinite collision model. Wire/cage/component editing still addresses original sources. The most recently completed/seeked root supplies shared Stock presentation. Hiding that root restores normal source presentation; showing it restores the derived result. Protected fallback stays red/topmost; user materials take precedence. No alternate mesh scene or renderer is created.

Dense diagnostics retain limits of 2048 cells/axis and 4194304 XYZ rays. Imports allow 256 occurrences/role, 1024 raw hits/ray and 16777216 raw events, bounded by device bindings. Planning allows 200000 events, 100000 distributed passes, 8192 tiles/query and 48 detour source boxes. Replay has eight checkpoints/64 MiB; fine tiles 64 MiB; cut presentation 2097152 patches. Capacity failure retires results instead of exporting partial paths. Nonempty Stock with balanced sampled crossings is required; empty/ambiguous Stock is diagnostic-only. Open Target/Protected surfaces are conservatively preserved. General broken/open solid interiors cannot be universally recovered.

## Source approximation contracts

The shared scene capture supplies sourceAccuracy metadata with reference, surfaceCertified, surfaceError, tessellationError, numericError and solidEnvelopeCertified. Distances are in geometry-local units. Native polygon documents use their canonical Float32 polygon surface as the reference, with zero source approximation; this does not retain an original external file's analytic provenance. Retained failed surfaces and unsupported evaluators remain unknown. Before full Slice, the shared scene.prepareAccuracy path rebuilds generated cached surfaces lacking an attestation. Morph and animated polygon vertices publish the guarded numerical contracts below. Instances follow the canonical owner's contract. Accuracy-only changes participate in scene signatures.

The shared spline worker proves bounds for supported cubic translation/ruled quads, straight planar cells and proved curved planar fills. Bernstein control-net second-derivative bounds cover interpolation and triangle splitting, with a separate guarded Float32 evaluation allowance. Exact Float64 dyadic checks validate shared boundaries and planar/straight special cases. Work is bounded to 4096 cells and 65536 control coordinates. A tight positive-error solid envelope requires closed matched parameter boundaries, one parametric component and one independently validated native component. General cells and unproved planar boundary families can instead publish the conservative enclosing-domain contract below. Multiple closed components retain a tight contract only after independent native component separation exceeds twice the local source error; otherwise they use the full-domain fallback. Invalid native triangulation and nonplanar purported caps still receive no certificate.

Curved planar caps, including proved disjoint hole loops and two-curve lenses, require exact control-point coplanarity. Monotone chord projections, separating control hulls and exact dyadic cubic bisections prove simple/disjoint authored boundaries. The worker additionally checks actual Float32 projected boundary simplicity, opposite exact outer/hole area signs, uniformly oriented nondegenerate triangles, oriented boundary incidence and opposite interior-edge incidence. Positive triangles and edge incidence alone can accept overlapping nested disks instead of an annulus; opposite hole orientation closes that gap. The native planar hint or a sampled contour alone is insufficient. A boundary-homotopy strip bounds fill disagreement; the reverse filled-surface distance uses a second boundary correspondence. Dominant-axis planar projection has operator norm at most sqrt(3), giving 2 sqrt(3) times the cubic chord bound plus 3 sqrt(3) times its numerical allowance. This is a filled-surface and closed-complex envelope, not a boundary-only error guess.

Each cap proof permits at most 64 cubic edges and 512 native vertices. A worker pass has 262144 planar predicate-work units; separating bisections have depth at most 12 and remain exact. Unsupported topology, nonplanar controls, invalid projected triangulation and capacity failures remain explicit unknowns. Unchanged cells retain only small proof metadata with the existing native incremental cache; generated triangle arrays are discarded. Independent cell proofs are retained even when another cell is unsupported, so repairing that source can certify unchanged neighbours without a full Rebuild. sourceAccuracyMs reports proof wall time. Straight monotone translation rails can use physical position as their parameter, so nonlinear cubic speed adds no fictitious geometric error. Coarse authoring may still have a bound above machining Tolerance; no sampling or tolerance control changes silently.

Mill converts local errors to physical distance with a safe affine operator-norm bound. source.sourceAccuracy and accuracy.sourceAccuracyCertified/sourceErrorBound report this contract separately from native interior validation. Planning Stock/Target/Protected bounds, conservative height/collision fields and volume triangle coverage expand by the known source error. Approximation padding stays separate from numerical padding used for affine checks and cutter replay. Points outside the source band retain proved membership; the band remains possible material through every subtraction. Merely adding source error to a final distance would be invalid when subtraction removes or leaves thin regions.

Whole-part witness covers therefore enclose both native and proved authoring solids, including Stock minus cuts and Target union (original Stock intersect Protected). A completed cover can set finishedSurfaceCertified and authoringDistanceUpperBound only when every source envelope is proved and all directional errors are covered. Missing contracts, limited traversal and unresolved regions keep that flag false. nativeSurfaceCertified remains separate. inspect volume reports referenceModel, sourceErrorBound and its local sourceAccuracyCertified; sampled XYZ inspection retains its separate sampled accuracy contract. General-family enclosing bands and full-part accessibility frontiers follow the contracts below. A wide band or unfinished cover cannot supply a positive machining certificate.

## Whole-part native verification

A separate resumable whole-part audit covers all captured Stock and Target, including regions outside CNC boxes and Target absent from initial Stock. Its desired solid is Target union (original Stock intersect Protected); floating Protected is an obstacle, not required workpiece material. Certified cell interiors and exteriors provide witness points. A segment between opposite membership witnesses crosses the actual boundary, and guarded farthest-corner distance bounds cover every point of an uncertain candidate cell. Both material-distance directions and both surface-distance directions are checked. Derived bounded lattice fields choose witnesses without source-triangle readback; their nearest-site approximation cannot weaken accepted distance bounds. Unknown cells refine from Tolerance/4 toward Tolerance/64, with explicit unresolved and unvisited regions on limits. Native boundary certification never follows from cell diagonal alone.

status.partAudit reports the four directional covers, missingTarget confirmed/possible/initiallyMissingVolume, domain/source validation, nativeSurfaceCertified and nativeDistanceUpperBound. Covers measure candidate-region volume, not an exact occupied-material integral. A proved missing Target fails with MISSING_TARGET before N/G-code publication and retains error detail. A native certificate requires a complete domain and source proof, no missing Target, completed traversal and no unresolved distance cover. It compares original native GPU solids minus continuous sweeps against the native reference. Authoring approximation is propagated when the shared source contract is proved; unsupported contracts retain explicit unknown status. accuracy.nativeFinishedSurfaceCertified and partAuditComplete expose these separate results.

audit {scope:"part",maxCells?,maxBlocks?,maxMs?} continues the frozen final cut prefix at any Progress, independently of operation audits. An operation cannot be selected in part scope. Omitted scope remains operation. Whole-part and operation frontiers share the existing 32 MiB job budget and 65536-region per-audit bound. Cancellation commits only complete blocks; source/settings/scene/device changes retire both frontiers and owned GPU caches. Distance workspaces remain bounded derived CPU fields; peakScratchBytes accounts for their live buffers. Coarse Target-overlap priority finds missing material before spending work on ambiguous Stock boundaries. Complete traversal can still retain unresolved native error; it is not an accessibility proof.

## Progress and time

Only full success publishes N and sets root Progress=N. Progress covers all stream events, including tool/spindle/pause/modal events, and changes derived display only. Backward/random seeks restore immutable source or a bounded checkpoint and replay exactly the selected cut prefix. New seeks supersede older requests. Source/settings/relative-frame changes, cancellation, deletion, HASH/scene replacement and device changes retire derived resources. Common rigid assembly motion reuses physical results. HASH stores authoring, not GPU jobs; reopened Progress resets to zero.

Slice shows --:--:-- until completion, then a lower-bound time marked with a greater-than-or-equal sign. Feed/dwell time comes from the exact exported stream. Controller S/P values are quantized before recording (0.001 RPM / 0.000001 s); positive values below that precision are rejected. The displayed lower bound rounds down to whole seconds. Controller rapid speed, acceleration/deceleration and manual pause duration are unknown and listed separately. No artificial rapid-speed field is added. Export G-code is enabled only for complete results. Physical/text defaults use localStorage frame.mill.defaults.v1, excluding Progress. Parameters validate before mutation; failures stay in status without a standing diagnostics panel.

## G-code contract

LinuxCNC RS274 uses metric absolute XYZ in G54, XY plane, units/min feed and G61 exact-path mode. Root physical coordinates must already be configured G54 coordinates. Start at root home with the first tool installed and no G92 offset. Every manually changed tool must be preset to the same calibrated effective tip offset already active at program start. M0 does not provide an MDI touch-off session; no unverified offset change is inferred. The program establishes G21 G90 G17 G94 G40 G80 G61 G54 and M5 S0. It invents no machine-specific offset or homing macro.

Start G-code executes once. Tool Change defaults to M5 then M0 and must contain mandatory M0; M1 alone is insufficient, and the spindle must be stopped at each mandatory tool-change pause. Accepted custom state: finite metric/absolute G0/G1, G4 P seconds, G17/G21/G40/G54/G61/G80/G90/G94, F/S, M0/M1/M3/M4/M5/M7/M8/M9 and comments/line numbers. Every custom motion enters the common verifier/stream. G1 custom positioning must be clear air; it cannot silently cut. Feed/Plunge maxima apply. G80 clears the remembered motion mode; subsequent axes need explicit G0/G1. S alone does not start a stopped spindle; M5 retains commanded S.

Relative/inch modes, arcs, offsets, G28/G53/G92, G43, G64, M6, macros and custom termination are rejected until a machine-specific state model exists. Finish is generated once: verified home, M5, M30. Primary contracts: [LinuxCNC G-code](https://linuxcnc.org/docs/stable/html/gcode/g-code.html) and [M-code](https://linuxcnc.org/docs/stable/html/gcode/m-code.html).

## General source enclosures and deformation

General two-, three-, four- and five-sided evaluators bound their actual coefficient tables/ribbons before generated arrays are discarded. Cubic coefficient sign bounds, positive Hermite/blend weights and bounded pentagonal offsets enclose the entire reference domain; exact boundary control hulls are also included. Ordinary quad ribbons use an analytic control-box/tangent bound with a Float32 coefficient-rounding guard, avoiding per-cell rescans of their coefficient tables. The global enclosing-reference-domain band includes both the reference and native surfaces/solids. All possible disagreement lies in that native-boundary neighbourhood, so separate shell-isotopy assumptions are unnecessary. sourceAccuracy.solidBand and enclosingDomain identify this fallback; coarseReasons retains why a tight proof was unavailable. status.source.sourceAccuracy.coarseEnvelopes lists representative owner hashes and physical error bounds. The complete metadata participates in source identity.

This fallback can be as wide as the whole object. It is useful as a proved conservative bound, not a promise of machining precision. Planning/subtraction/part verification retain its full width; no error cap is applied to make a job succeed. Invalid planar triangulation, nonfinite data and global source-work limits remain explicitly unknown. A whole-domain fallback can exceed machining Tolerance, in which case the whole-part result stays uncertified; no requested precision is silently weakened.

A polygon Morph bounds every sparse authored weight/delta quantization and multiply/add against the original Float32 base. The shared core uses a guarded gamma bound and rejects excessive arithmetic counts. Point animation bounds each uploaded Float64 position's Float32 rounding. These contracts belong to the exact evaluated geometry version. One closed component uses its matched polygon homotopy. Multiple spline components retain their tight local bounds only when guarded GPU triangle-box separation exceeds twice the source error and native/parametric component counts agree; otherwise they use their full-domain fallback. Multiple deformed polygon components use the full-domain fallback. Independent native source validation remains mandatory. General cached HASH surfaces are rebuilt through the common evaluator when their attestation is missing; proof data is not trusted from a file.

## Continuous residual accessibility

Each possible excess leaf has separate inaccessibleVolume, reachableVolume and unresolvedVolume. A certified interior point of Target/Protected is an obstacle witness. For every XY centre box capable of touching any point of the excess region, the proof bounds the highest contacting cutter tip. If a witness is inside the cutter even at that tip for every centre in the box, every lower contacting pose is blocked too. Otherwise the centre box subdivides. Flat, Ball and V use the same infinite analytic cutter model as the program; Ball profile bounds remain guarded near tangency. A finite set of samples can provide witnesses, but only the complete adaptive pose-domain cover can certify inaccessibility. Missing witnesses produce uncertainty, never free-space or inaccessible claims.

Witness queries try 16 and 32 cells on their longest dimension, retain at most 8192 proved points, and keep source triangles GPU-owned. Each region permits 2048 pose boxes/50 ms, with 64 region queries/500 ms per audit pass; a completed GPU query or pose box can extend a limit. Each proof also stops at a guarded centre size R/65536. Up to four small certified seed queries per region search inside source bounds when a thin obstacle has no coarse interior witness; seed cursors and proved points survive continuation. Source/domain validation is required for residualAccessibilityCertified. Whole-part checking transforms each candidate region conservatively into every supported operation frame; a region must be inaccessible in all setups. Material outside a setup's physical box is excluded for that setup. The whole-part result includes the entire captured Stock/Target domain and the frozen final cut prefix, independently of Progress.

A whole-cell safe operation pose is reported reachable. Up to three additional local refinement passes use ordinary entry/transition, quantization, continuous sweep verification and the common motion stream; the volume audit restarts after a cut. Proved reachable excess left afterward fails UNRESOLVED_STOCK before N/G-code publication. Traversal limits and terminal unresolved leaves remain explicit. Unresolved accessibility leaves stay in the same packed frontier with an explicit region kind, sharing the 32 MiB queue budget and transactional block commits. Their volume is separate from unvisited material and is never counted twice. Physical volume traversal completion and accessibility completion remain separate. Continued passes refine these regions, while thin-obstacle seeds use guarded small certified cell queries, retain bounded proved witnesses and release them on retirement. Witness/seed caches have a separate shared 32 MiB job budget. Limits and still-unresolved cases retain the frontier and cannot set the accessibility flag. The full CAM program's complete state does not imply residualAccessibilityCertified or finishedSurfaceCertified. Whole-part reachable cells trigger up to three additional correction cycles in native setup preorder, carrying actual stock/position and using ordinary tool-change clearance/M5/M0/restart validation. Safe lower poses can clear the complete residual column; every cut still uses the common verifier.
