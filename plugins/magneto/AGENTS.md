# Magneto

GPU 3D nonlinear magnetostatics: ferromagnetic saturation, persistent vector hysteresis and remagnetizable permanent magnets, 3D conductor current continuity and Biot–Savart excitation, Maxwell stress and Lorentz forces/torques, probes, interactive slices, 3D field strokes and Curves.

- Owner `magneto` parameters: `Auto size` (boolean, default `false`) and `Voxel size` (mm, default `2`). Manual boxes use the 100 mm local cube frame converted to right-handed SI axes (sheared frames reject `SHEARED_DOMAIN`); `Auto size` hides the box helper via `showHelper` and auto-fits participating magnetic/conductor bodies, `Current` planes and `Probe` helpers with magnetic air padding.
- Helper objects `magneto_current` (`Current`, 100×100 mm XY cut plane with `+Z` normal arrow, signed animatable `Current Density` in `A/mm²`, hidden `Magneto` owner link) and `magneto_probe` (`Probe`, 2 mm crosshair cube at owner origin, hidden `Magneto` owner link) link explicitly to their `Magneto` owner hash.
- Single tag `magneto` (`M`, `inherit: 'nearest'`): `Material` presets (`Electrical Steel M19`, `Electrical Steel M27`, `Pure Iron`, `NdFeB N35`, `NdFeB N42`, `NdFeB N52`, `Ferrite Y30`, `Alnico 5`, `Copper`, `Aluminium`, `Custom`), conditional `Magnetization` (`+Z`, `-Z`, `+X`, `-X`, `+Y`, `-Y`, `Unmagnetized` via `visibleWhen.in` for hard magnets and `Custom`), and `Custom` fields (`Permeability`, `Saturation` T, `Remanence` T, `Coercivity` kA/m, `Conductivity` MS/m). `surfaceStyle` fallback applies only when no effective native Frame Material exists and never mutates materials.
- GPU triangle-centric 3-axis ray-parity + shrunk-SAT (`0.495`) voxelizer borrows canonical buffer and paged-texture resources directly without a CPU triangle mirror.
- Current continuity solver (`CURRENT_WGSL`) solves $\nabla\cdot(\sigma\nabla\phi)=0$ with a branch cut across each `Current` plane inside intersecting closed conductors (or domain-spanning busbars) to produce divergence-free 3D current density $\mathbf{J}$ scaled to the authored `Current Density` (`A/mm²`), followed by tiled GPU Biot–Savart (`BIOTSAVART_WGSL`) for source field $\mathbf{H}_s$.
- Nonlinear magnetostatic solver (`MAGNETO_WGSL`) solves reduced scalar potential $-\nabla\cdot(\mu(\mathbf{H})\nabla\phi) = -\nabla\cdot(\mu(\mathbf{H})\mathbf{H}_s + \mu_0\mathbf{M}_r)$ with harmonic face permeability, flux-continuous remanence weighting, and 2nd-order dipole Robin open-field boundaries using symmetric Red-Black SSOR-preconditioned GPU PCG inside a damped nonlinear loop updating Fröhlich–Kennelly soft-ferromagnet permeability and vector hard-magnet hysteresis.
- Hard magnetic bodies retain persistent body-local remanence $\mathbf{M}_r^{\text{local}}$ (transported rigidly under object rotation/translation across frames in `solve-animation` and between `solve-frame` runs). Fields approaching or exceeding intrinsic coercivity $H_{cj}$ irreversibly demagnetize, rotate, magnetize (`Unmagnetized`), or flip $\mathbf{M}_r^{\text{local}}$; `reset-magnetization` (`Reset M`) restores authored initial magnetization and is shown only when persistent remagnetized state exists.
- Per-body `Force (N)` and `Torque (N·m)` about each object's native pivot integrate the air-shell Maxwell Stress Tensor for magnetic bodies and Lorentz volume $\mathbf{J}\times\mathbf{B}$ for conductors; `force`, `torque`, `measure`, `status` and clickable `Curves` readouts expose these results.
- Transient display controls in Attributes (`B`, `H`, `M`, `Sat`, `Voxels`, `Strokes`, `Slice Off/X/Y/Z`, `Slice (%)`) never mutate HASH/Undo. Viewport rendering draws smooth 3D-texture (`rgba16float`, 2-pass solid dilation) surface maps on borrowed canonical meshes clipped by `surfaceFilter`, a diagnostic `Voxels` shell (showing N/S poles, steel and conductors), 3D `Strokes` field arrows, and a blended interactive `Slice` plane. Cursor `surfaceProbe` reports local `|B|`, `|H|`, `Sat %` and material/pole.
