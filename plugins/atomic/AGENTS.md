# Atomic

Read `plugin.js`, `plugin.json` and `provenance.json` before changing physics/persistence. Runtime embeds NEP89-1 weights, NEP4/ZBL kernels, charge diagnostic and license; provenance.json pins model source. Preserve energy/descriptor kernels, use shared device.

- One Atomic owns one world. Units: angstrom/fs/eV/amu; Temperature Celsius, Damping inverse ps, Time scale fs/s. Object affine motion never changes internal atom coordinates.
- Selection pauses physics; edits preserve velocities. Fixed atoms interact but skip integration. Velocity initializes local XYZ angstrom/fs once; Force continuously applies local XYZ eV/angstrom. Confinement is nonnegative constant-magnitude eV/angstrom toward local pivot, zero at pivot; do not alter NEP kernels.
- Store/Restore saves positions only, requires same stable IDs; restore clears velocity/clock/derived state, preserves playback. Zero time does not initialize NEP. Persistent typed arrays have separate HASH records; exclude runtime force/velocity/neighbors/charge/draw state.
- Common 60 fps timeline waits for Time scale/60 fs in every enabled independent world and all GPU output, no wall-clock catch-up. Fixed PSR animation precedes physics; Loop wraps authored frame while continuing physical state. Pause stops scheduling and drains current multi-world frame. No Atomic-local playback timer.
- Green disable freezes world positions/momentum/clock without catch-up or hiding. Disabled Fixed releases atoms; re-enable anchors current centers and persists reanchored reference. Disabled Force stops acceleration without clearing momentum. Velocity re-enable mid-run never injects a second impulse. Red visibility (including species/selections) never changes physics.
- Scrub evaluates animation/Fixed without integrating or rewinding. Video resets enabled worlds to stored/initial positions, evaluates frame zero without stepping, then every physical interval including preroll before nonzero start; still output consumes no time. Only Viewport renderer includes Atomic impostors; do not accidentally route them into native path tracer.
- Species native material rows use dynamic membership; selection materials override species. Charge color caps at 32768 atoms and is not electrostatic force. Appearance does not change species/physics; opacity/textures/roughness pipelines are omitted.
- Reuse native periodic table/gizmo/hierarchy/history. No per-atom Browser rows or private playback/UI. Detached atoms become native 20-triangle sphere instances; large groups use common child limits/material subgroups.
- Coherent display publication couples atom/bond GPU buffers with GPU-reduced bounds from the same completed snapshot. Hierarchical 128-way reduction uses actual species Float32 radii, outward one-ULP bounds and six extrema+two validation words (32-byte readback), not CPU atom mirror or authoring P. Solver metadata/reduction mappings must both validate before synchronous publication.
- Paused preview lazily separates working buffer on first GPU edit (64*N bytes); reuse it thereafter, never allocate for navigation/owner PSR. Reduction workspace is bounded by hierarchy. While mapping waits/fails/cancels, keep last complete display/bounds; retirement invalidates pending publication. Shared pipeline compilation can retry. Navigation uses cached summary, never O(N) CPU traversal.
- Whole visible world bounds conservatively include hidden memberships; hidden/Solo-excluded owner contributes nothing, disabled visible owner still contributes. Non-rendering selection rows must not add stale clipping bounds. Render-only worlds are not native replica sources; detached atoms are sphere instances.
- For 8192+ atoms choose serial/cooperative kernels from measured profiles after shared pipeline readiness. Work packets target 8 ms, queue depth 2 for fast steps/up to 8 for long steps. Force inspect first evaluates pending constraints. Preserve stable physical timestep/NEP math while changing scheduling.
- Scale edits centres, never display radii. One atom uses reduced Move gizmo; Fixed retains full controls. Orthographic placement intersects world grid and only quantizes when enabled. Placement survives navigation, ends on editing/right-click/Escape. Dynamic selection bounds must validate authoring identity before membership allocation.
- plugins.describe owns schemas; inspect <=4096 atoms. Temperature >=-273.15, Damping/Time scale/Confinement >=0; manifest declarations govern all writes. Diagnostics stay in automation.

Checks: npm run test:atomic; npm run test:atomic:comparison; npm run test:atomic:performance. tests/index.mjs owns catalogue checks; nep-reference.json retains independent force/energy expectations/provenance. Mega-scene generator stays reproducible; million-atom display/edit/history measurements do not establish physics throughput.

Specific regressions: `tests/display-bounds.mjs` (held/failed maps, one-time allocation, retirement), `tests/physics.mjs`, `tests/comparison.mjs`, `tests/performance.mjs`, `tests/million-physics.mjs`. Comparison uses unchanged supplied original on same GPU; distinguish initialization/physics from preview/edit throughput. A green-disabled mega-gallery is not million-atom physics evidence.
