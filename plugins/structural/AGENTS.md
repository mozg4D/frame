# Structural

GPU voxelized linear-elastic Hex8 FEM, unilateral frictionless contact and SIMP topology optimization.

- Owner `structural` parameters: `Auto size` (boolean, default `false`), fixed `Voxel size` (mm, default `2`) and `Material (%)` (default `30`). When `Auto size` is enabled, the 100 mm box helper is hidden via `showHelper` and the domain continuously auto-fits participating tagged geometry with no box-cut fixing. Manual boxes use the native affine frame converted to right-handed SI axes (sheared frames reject `SHEARED_DOMAIN`); material bodies continuing across a manual box wall into the 1-voxel ghost pad clamp their cut-face nodes (`u = 0`).
- Five tags: `structural_material` (12 engineering presets, nearest inherited), `structural_fixture` (nearest; volume overlap = rigid weld, non-overlapping face touch = frictionless unilateral contact), `structural_force` (`multiple: true`, additive inherited, compact `Force (N)` and `Torque (Nm)` world-coordinate vector rows about the owner's native pivot; volume fraction outside a manual box is discarded proportionally), `structural_optimize_space` (fieldless) and `structural_preserve` (fieldless). Own mass gravity (`-Y`, `9.80665 m/s²`) is always enabled.
- Multi-body overlap union-find welds overlapping material bodies and splits nodes for non-overlapping touching bodies with frictionless unilateral contact. Pre-solve rank-6 rigid-body validation rejects unconstrained parts (`UNCONSTRAINED_RIGID_BODY`) before publishing any stress.
- GPU triangle-centric 3-axis ray-parity + shrunk-SAT (`0.495`) voxelizer and signed volume integrator borrow canonical buffer and paged-texture resources directly without a CPU triangle mirror.
- GPU matrix-free Hex8 PCG (`PCG_WGSL`, 7 storage buffers, translation-invariant element matvec, race-free CSR contact adjacency) runs inside an active-set unilateral contact outer loop, followed by 8-Gauss-point von Mises stress, `Safety factor` (never `Min safety factor`), displacement and mass post-processing.
- SIMP (`optimize-frame` / `optimize-animation`) optimizes `Optimize Space` (or all material when absent) while locking Preserve/Fixture/Force/cut voxels, supports shared multi-load-case optimization across animation frames, extracts a support-connected binary solid verified with exact zero-void full stiffness, and reveals `Result to Object` (hidden until qualified optimization) to publish a closed watertight Surface Nets native polygon `mesh` via `context.document.createMesh` with Undo/Redo.
- Animation load cases (`solve-animation` / `optimize-animation`) evaluate keyframes plus changing intervals while skipping unchanged held tails, archiving frame summaries for clickable `Curves` readouts (`Safety factor`, `Stress (MPa)`, `Displacement (mm)`, `Mass (g)`).
- Display switches (`SF`, `Stress`, `Disp`, `Voxels`, `Density`) and transient `Deformation (×)` live only in Attributes; 3D world Force/Torque arrows follow deformed voxels; cursor `surfaceProbe` reports local SF/MPa/mm or Material/contact role; `surfaceFilter` clips original meshes inside the active domain. All solver/grid/density caches stay outside HASH.
