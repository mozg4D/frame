# Shared plugin contract

## Discovery and authoring

- Each plugin directory contains exactly AGENTS.md, icon.svg, plugin.json and plugin.js, plus an optional tests/ directory. Keep all runtime code in plugin.js and provenance in plugin.json; test-only helpers/fixtures belong under tests/. Do not add runtime sidecar files or directories.
- Catalogue: plugins/index.json; manifest: <id>/plugin.json; export activate(context). IDs match directories, object types are unique; assets stay same-origin inside plugins. Activation runs once before use and creates no owner itself.
- After window load and editor readiness, idle preloading fetches the plugin icon catalogue and SVGs only. Plugin manifests and modules remain lazy; Plugins tab discovers metadata/icons without executing unused modules, and HASH loads required modules only. Unknown tag ownership may require catalogue metadata. Explicit plugin discovery opens Plugins initially. Offline availability requires prior use in the current shell cache.
- Manifest fields: finite number, boolean, choices (first default), string reference. Literal strings use textFields. fieldOptions declares units/bounds/integer/access once for Attributes/API/fields; context.parameters.schema(type) supplies operation schemas. Shared field writes require explicit read-write access; animated/reference fields remain unavailable there.
- Tags accept finite numeric/boolean defaults and homogeneous enum choices (64 fields, 64 choices, keys <=128 chars), plus optional `fieldOptions` (`unit`/`minimum`/`maximum`/`integer`), compact XYZ `vectors`, `multiple` instances (`add:true` and `uid`-targeted edit/remove on `tag.set`) and `inherit` (`'none'|'nearest'|'additive'`). Strings/references and tag-level `ranges` remain unsupported. tag.set/read/list, native UIDs/animation/Undo/HASH own authoring; scalar storage alone is not physics.
- Native document/hierarchy/frames/selection/materials/transactions/history remain authoritative. First-party plugins also receive `context.core` (the same `window.frameCore` object exposed to Scene Control, including `engine`, `nodes`, `spline`, `geometry`, `morph`, `control`, `transaction` and `refresh`) for direct access to native subsystems without artificial wrapper gates. Borrow context.device; release only owned resources. The root architecture rules apply: no second scene/editor/device or permanent CPU mirror.
- Never await serialized context.api.call inside activation/operation handlers. Create in one native transaction then await context.editor.selectOwner when needed. Post-commit selection errors are not rollback or permission to repeat creation.

## Geometry and async work

- context.gpu(hash) borrows canonical buffer/paged-texture resources. Never map/write/destroy them; reacquire after revisions.
- Optional third-argument bounds:{min:[x,y,z],max:[x,y,z]} on scene.capture/scene.signature filters evaluated occurrences against conservative owner-local bounds. Use the same bounds for capture and later certificates; includeHidden remains independent. Bounds are a broad phase, not exact clipped geometry.
- context.scene.capture(hash,parameterKeys,options) supplies evaluated GPU occurrences and owner-local matrices/signature. Optional `{includeTags:true}` adds `worldMatrix` and inherited `nearest`/`additive` tag provenance (with owner world/pivot frames) hashed into signatures. By default hidden/history/consumed geometry is excluded, independently of frustum. The snapshot represents the current evaluated pose.
- `context.animation.inspect(hashes)` returns detached tracks and object, source, native parent and active Target dependencies. `context.animation.sampleTransforms(hashes,timeSec)` samples native affine world matrices in millimetres at fractional frames. It shares the live PSR, Target and camera orientation evaluator and leaves the timeline and GPU surfaces untouched. The same read-only operation is exposed as `animation.sampleTransforms` with `ids` and `timeSec`. A transform describes a fixed local material point. A deformed surface also requires its evaluated local displacement.
- Recheck context.scene.signature before subsequent submissions/publication. Scene/device/resource/relative-frame/visibility/captured-param changes invalidate. Jobs own cancellation, atomic output and retirement; HASH stores authoring only.
- Optional `{includeHidden:true}` on both scene.capture and scene.signature includes display-hidden evaluated occurrences, including compact instance clouds, independently of red visibility, hidden ancestors and Solo. Calculation-disabled geometry and consumed generator/Boolean/clone inputs remain excluded; disabled generators reveal eligible operands as in the native evaluator. Use identical options for capture and every later certificate. This supports builds and completed results that survive display visibility changes while still rejecting geometry, relative-frame, deletion, document/device and captured-param changes.
- context.fields.authoringStamp() synchronously returns frozen {epoch,revision} or NOT_READY/BUSY without joining FIFO. Capture scalar inputs/stamp in one JS turn; fresh-check after every await and before use. Navigation can temporarily be BUSY without changing physical inputs. Stamp is not a geometry/eligibility certificate; retain source checks.
- context.document.setRecord(hash,key,type,values) stores immutable typed authoring at 32-hex identities. Replace values, do not mutate arrays. Native copy/HASH remaps declared refs; undeclared extensions may be omitted with diagnostics, not promised lossless.

## Native extension points

- Owning core code is `FramePlugins`, `FramePluginRecords` and `FramePluginTags` in index.html. Read shared dispatch and matching native serialization/validation before adding hooks; manifest declarations do not automatically imply supported editor/capture semantics.
- `context.hash` exposes the shared native HASH codec; `context.document.codec` exposes its binary value encoder/decoder, storage adapter and cache keys. Use it for plugin data/preferences; do not serialize native authoring/history/cache stamps through JSON. Static package manifests and external format/API boundaries retain their declared formats. An optional manifest recordTypes map declares exact native types for owned records; writes and HASH preflight reject mismatches. Structured data uses binary values/bytes; no JSON decoding or migration is supported.
- `context.document` operates on actual native nodes/records/frames/materials plus transactions/checkpoints and `createMesh` for native polygon publication; `context.math` is native affine math. Hooks in context.editor supply parameter validation, created defaults, documentChanged invalidation, copy/reparent/restore, component GPU pick/snap/bounds/transforms and animation/flush. Validate parameters before mutation; derived controls may forbidAnimation. Do not silently patch owner selection after unrelated newer selection wins.
- `disable:false` omits green control for noncomputational rows; `enabledAffectsVisibility:false` separates calculation from red visibility. Status/display must honor those declared policies, not equate hidden with disabled.
- `scene.capture` bounds are conservative local broad phase, not geometry. sourceAccuracy comes from shared evaluator: exact document polygons versus proved/coarse/unknown generated/deformed envelopes. It participates in signatures. `scene.prepareAccuracy()` rebuilds missing current generated attestations before capture, without changing authoring. Never treat unknown as zero error or retain borrowed snapshot as public status.
- Native tag identity is owner+UID; duplicate may keep same UID on another owner. Validate all target tags/merged params before one Undo. Fieldless tags, declared scalar tags and unavailable opaque payloads have different semantics; reading a tag must not activate unused runtime. Generated canonical UIDs must be valid native 32-hex IDs, including animation binding fallback.
- `editor.surfaceStyle(hash)` is a fallback only when no effective native user material exists; never creates saved material. `surfaceFilter(hash)` returns stable derived fragment predicate/buffers, optionally tied to an owner whose visibility/ancestors/Solo suppress it. Native shading keeps actual inherited materials/face masks/UV. Returned buffers stay plugin-owned/alive; bridge owns derived pipeline/bind caches. Wire/cage/editing still addresses source geometry.
- Dynamic Attributes may declare hiddenFields, labels, ranges, groups/actions and numeric step hints. Actions support placement:'bottom', progressAlign:'left' and a live hidden flag. Hide a grouped row when all of its actions are hidden. Labels rename presentation, never stable field keys. Manifest units/ranges take precedence; refresh must preserve active edits. Arbitrary technical logs and fake measurements do not belong in Attributes.
- Optional Attributes readouts display measured values in labelled columns (`height:auto`; single-column empty heading renders compact label/value on one row). Each row has a stable id, a label, column names and formatted values. A null value array hides the row. Refresh readouts in place so an asynchronous calculation preserves native focus and edits.
- Empty helper lines permit render-only descriptors. Lazy activation completion after scene Open requests redraw even without native triangles. Compilation failure is activation error with retry, not a reason to publish partially created derived data.

## Rendering and operations

- Optional `axisLines` gives three distinct zero-based segment indices in X, Y, Z order on a viewport or per-type helper. These lines share the world-axis colours for the active projection, including selection and guides-only views.
- context.viewport.register owns local helper lines/bounds/pivot, optional `showHelper(hash,params)` helper visibility predicate, settings/surface-warning shader and render/retire hooks on the shared bridge. Render borrows open pass/camera/frame/device; never end/destroy them. The render callback and `context.editor.view()` report the current view's `shading` mode. requestDraw schedules rendering; requestAttributes refreshes actions/plugin overlay.
- context.viewport.isVisible(hash) reports the registered owner's effective viewport visibility, including ancestors, enabled policy, Solo and Solid/Lines mode. Reuse it for custom navigation queries instead of treating draw callbacks as a per-frame visibility ledger (cached views need not redraw).
- A viewport can supply `surfaceProbe(hash)` for a cheap availability check and `surfaceProbe(hash,hit)` for a native surface reading. The hit contains the occurrence hash, position/index resources, occurrence world matrix, original triangle index and picked world point in millimetres. Return `{text}` or null. The host coalesces pointer events, resolves the nearest evaluated surface on the renderer, and manages the value beside the cursor. Set `surfaceOrder:'selected-smallest'` for overlapping result boxes. The selected owner takes priority, followed by the smaller transformed helper volume.
- Result readouts can supply a lazy `series()` returning `{labels,unit,samples:[{frame,values}]}`. Click opens these channels in native Curves. Shift-click adds them to the current curves. Computed samples are read-only and missing frames create gaps. Keep the returned data identity stable while measurements stay current.
- `context.animation.timeline()` reads the native playhead and inclusive end frame. From a background job, `context.animation.seek(frame,fromFrame,guard)` queues a compact native seek, waits for the evaluated scene and protects an intervening playhead move. The optional synchronous guard can revoke a queued visit before it changes the frame. Return a job handle before scheduling these visits. Playback and navigation alone do not request a simulation.
- renderKind: solid (default, Solid on), overlay (Solid or Lines), helper (also both off). stage selects opaque or overlay (default) for helpers/warnings and callbacks; optional renderStage overrides only the callback stage. Ordinary callbacks share scene depth. Visibility/enabled policy/ancestors/Solo still apply. Line-only warnings use evaluated depth; both off suppresses warnings.
- Optional surfaceWarningBlend:true honors pluginSurface alpha with source-alpha blending. It composites beneath plain polygon strokes and protects native raster/cage line pixels using shared GPU coverage; no extra scene copy or line redraw. Default warning rendering remains opaque.
- Optional independentDepth:true gives the render callback a separate cleared overlay depth pass. The bridge reuses one tracked depth24plus target per view, retires it on resize/view closure/device teardown, and leaves warning/helper depth on the ordinary scene. Callbacks may depth-test/write for self-occlusion while remaining visible over source geometry. It adds no geometry copies.
- Per-type helpers use viewport.helpers. Custom geometry needs matching shared bounds/picking support before claiming viewport selection.
- Optional context.viewport.cameraWGSL defines frameCameraRelative(rotation): subtract 3.2 from translation Z, eye-Z becomes zero. Insert after WGSL directives; projection/inverse reconstruction both use returned translation. Borrowed camera remains 144 bytes/36 floats; Float32 camera-origin error remains.
- context.operations.register owns schemas/readOnly/run; plugins.command validates before dispatch. Long jobs return handles promptly. context.update uses native Undo. Attributes actions use native controls; only Printer Slice may show short progress. Diagnostics belong in API.
- Plugin Attributes may return transient `numbers` for computed display settings. Each row supplies its current value, label, bounds, visibility and synchronous setter. Native numeric editing, scrubbing and Escape apply without changing the scene or key tracks.
- context.editor integrates component selection/transforms/copy/animation/flush. Offline `flush({output:true,frame,present,signal})` waits for physical readiness. Video preroll has `present:false`. An export aborts its signal when stopped. `context.viewport.isVisible(hash,mode)` accepts the output shading mode independently of the active editor view. The shared 60 fps timeline owns playback.
- editor.navigation(x,y) may asynchronously return {depth} in the native camera ray's parameter units. Navigation dispatch awaits every provider and chooses the nearest finite positive depth; an asynchronous miss must not intercept later plugins. Query actual displayed geometry, retain bounded readbacks and reject stale asynchronous results.

Each plugin owns one AGENTS.md and tests/index.mjs exporting async pluginChecks(page) -> {pass,checks,timings,error?}; keep fixtures/helpers local. Standard/stress runs Atomic checks by default; other plugin checks run only when explicitly requested with --plugins=<id,...> or --plugins=all. Root owns global verification/publication rules; plugin documents own only specific limits/commands.

## Change checks

Native integration requires create/select/transform/Undo/copy/clipboard/merge/HASH tests as applicable, plus shader/native pixels when draw paths change. In particular, check host field declaration vs native preservation, source revision changes after every await, source-only and paged/instanced geometry, hidden ancestors/Solo, device teardown and cancellation. `tests/plugin-infrastructure.mjs`, `tests/plugin-tag-fields.mjs`, `tests/plugin-warning-modes.mjs`, `tests/authoring-stamp.mjs`, `tests/plugin-overlay-refresh.mjs` and `tests/plugin-loading.mjs` are shared entry points; do not duplicate plugin-specific contracts here.
