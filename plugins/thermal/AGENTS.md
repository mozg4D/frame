# Thermal

GPU conjugate heat transfer (CHT): solid conduction with harmonic material interfaces, 3D fluid flow with Boussinesq buoyancy and Fan P–Q actuator momentum forcing, wall-function convection, Stefan–Boltzmann surface radiation, transient timeline simulation, Probes, interactive air slices and Curves.

- Owner `thermal` parameters: `Auto size` (boolean, default `false`), `Voxel size` (mm, default `2`), `Medium` (`Air`, `Water`, `Vacuum`), `Ambient` (°C, default `20`), `Initial` (°C, default `20`), and `Time scale` (`s/s`, default `1`). Manual boxes use the native affine frame converted to right-handed SI axes (sheared frames reject `SHEARED_DOMAIN`); `Auto size` hides the 100 mm box helper via `showHelper` and auto-fits participating thermal geometry/fans/probes with air padding (`Air`/`Water`) or tight padding (`Vacuum`).
- Helper objects `thermal_probe` (2 mm cube + crosshairs at owner origin) and `thermal_fan` (10×40×40 mm box + shroud ring + `+X` airflow arrow at `[-30, 0, 0]` mm, `Shutoff pressure` default `25 Pa` labelled `Pressure`, `Free flow` default `0.005 m³/s`, hidden `Thermal` and legacy `Direction` fields) link explicitly to their `Thermal` owner hash and support arbitrary orthogonal 3D placement and rotation.
- Three tags: `thermal_material` (17 engineering presets + `Custom` with conditional `Conductivity`, `Density`, `Specific heat`, `Emissivity` via `visibleWhen`, nearest inherited), `thermal_heater` (`multiple: true`, additive inherited, signed `Power (W)` supporting both heating and cooling, conserved uniformly over active solid voxels with proportional manual-box clipping), and `thermal_temperature` (nearest inherited, fixed Dirichlet `Temperature (°C)`). Objects tagged with `Heater` or `Temperature` without `Material` automatically fall back to `Aluminium 6061`.
- GPU triangle-centric 3-axis ray-parity + shrunk-SAT (`0.495`) voxelizer borrows canonical buffer and paged-texture resources directly without a CPU triangle mirror.
- Coupled GPU solver (`FLUID_WGSL` semi-Lagrangian advection + Smagorinsky viscosity + Boussinesq buoyancy + Fan P–Q forcing + Red-Black SOR pressure projection; `ASSEMBLE_WGSL` + `BICG_WGSL` row-normalized 7-point FVM M-matrix BiCGSTAB with RB-SOR breakdown recovery, solving temperature rise `theta = T - T_amb`) runs for both `solve-steady` (Picard CHT + radiation coupling; rejects `NO_HEAT_SINK` in Vacuum when `Emissivity == 0` and no `Temperature` tag exists) and `solve-animation` (unconditionally stable backward-Euler transient stepping across timeline frames with dynamic animated `Heater`/`Ambient`/`Fan` updates and bounded 64 MiB scrubbable field snapshots).
- Viewport display renders smooth 3D-texture (`rgba16float`, 2-pass solid dilation) thermal/flux shading directly on borrowed canonical meshes clipped by `surfaceFilter`, a diagnostic `Voxels` shell, 3D `Flow` arrows, and a blended interactive `Slice` plane (`Off`/`X`/`Y`/`Z` + transient `Slice (%)` scrubber). Cursor `surfaceProbe` reports local temperature/material/flux or voxel role; `Thermal` and `Probe` readouts expose clickable `Curves` series.
