# Cut authoring foundation

Cut is an independent native plugin for a future flat cutting and line-marking workflow. This milestone implements authoring, not CAM. Generate is disabled. The API rejects generation, source extraction, result and save with CUT_AUTHORING_ONLY. There is no job, toolpath, preview sequence, estimated time, G-code position or export file. Empty and populated scenes are both unqualified; no empty successful job is fabricated. No physical machine is contacted.

The native rectangle is 1000 × 1000 mm in local X/Z, with pivot at (0,0,0). Positive X is right and positive Z is up in Frame Top, so the pivot is lower left. The head-side normal is negative Y. Red X and blue Z sides meet at the pivot. Ordinary native size/scale, rotation, hierarchy and position edit the same owner frame. Future program X/Y must map to local X/Z, never world X/Y. Multiple owners are independent. Native enabled/visible controls remain intact.

Attributes provides the native Cut/Mark choice, Speed (mm/min), integer Passes, Line width (mm), Lead-in (mm), and four multiline text fields. Initial values are 1000 mm/min, one pass, 0.2 mm width and 1 mm lead-in. These are editable authoring placeholders, not a qualified machine/material recipe. Speed is at least 0.001; Passes is a positive safe integer; widths/distances are nonnegative. Machine blocks start empty because no machine dialect was supplied. Blocks preserve Unicode, comments, blank lines and unknown commands, up to the common field limit of 16384 UTF-16 code units per block. Native textarea editing uses browser newline normalization; API/HASH preserves the supplied string. Nothing parses, substitutes, executes or emits these blocks yet.

The existing native action layout places disabled Generate above fields; matching the concept's final Generate/time row below machine blocks is deferred until generation exists. No diagnostic row, popup or fabricated red error state is added. The plugin catalogue identifies this as an authoring preview.

Avoid (`cut_avoid`) and No-cut (`cut_no_cut`) are native fieldless tags on ordinary geometry. Their intended meaning is no head entry even during travel, versus no active tool with travel permitted. Geometry projection and enforcement are unavailable in this milestone; assigning a tag is metadata authoring, not a protection certificate. Native tag removal disables participation.

## Persistence and API

Every setting resides in ordinary owner params and native HASH/Undo/duplicate. Object `textFields` distinguishes literal text from reference fields; `fieldOptions.access` makes all technology fields available through fields.list/read/write with canonical `param:<key>` IDs and CAS. Existing reference fields keep their own behavior.

The stable localStorage key `frame.cut.settings` stores version 1 technology settings. Native parameter edits are observed after commit; restored node identities force a complete deterministic reconciliation. A sole selected Cut wins when reconciling multiple restored owners; otherwise the last Cut in native document-array order wins. Single changed owners update defaults irrespective of selection. New Cut creation applies these defaults only in its native created hook. Explicit API parameters, duplicate and HASH values retain priority. Scenes without Cut preserve the last profile. Positions, dimensions and generated data are never local technology defaults. Storage failure keeps usable in-session settings and is exposed as `defaults.storageAvailable` in status. Future schema changes must preserve existing blocks rather than reset them.

Use `plugins.create {plugin:'cut'}` or `scene.create {type:'cut'}`. Discover operations with `plugins.describe {plugin:'cut'}`. `plugins.command {id:<hash>,operation:'status'}` returns explicit availability, parameters, local plane convention, defaults provenance and viewport preparation errors. `generate`, `sources`, `result` and `save` reject CUT_AUTHORING_ONLY; `cancel` returns `{cancelled:false,job:null,reason:'CUT_AUTHORING_ONLY'}` because no work is scheduled. Ordinary scene.update and fields.write validate before authoring mutation. Native tags use tag.set/read. No plugin-local parameter registry or geometry cache exists.

## Verification

`node plugins/cut/tests/model.mjs` checks constraints, exact opaque strings, applied defaults, independent owners, native restoration selection, storage failure and a completed 10000-validation latency budget of one second. `tests/index.mjs` is discovered by the shared plugin suite and covers real icon creation, native controls/text/Undo, CAS, invalid writes, defaults, tags, HASH, unavailable operations and hardware frame timings. Full geometry, G-code, route accuracy and machine safety acceptance are not claimed. See PLAN.md for remaining acceptance work.
