Task queue

What is being worked on, what comes next, and what is still being discussed. Priorities can change as the work reveals new constraints. The current site is a development build; the public product release follows completion and testing of the slicer and practical print workflow.

Updated 4 October 2026

Current work

In progress

Priority: adaptive perimeter placement and extrusion transitions, guarded source-first geometry, and the practical import, slice, and print workflow.

  • Adaptive perimeter placement and flow

    Develop paths from preserved source boundaries before the fixed inset can discard thin material. Nominal width remains the default; exceptional strips, acute tips and through-necks need measured local width, separate commanded flow and nozzle geometry, reliable boundary endings and curved or branched material routes. Outside boundaries and holes precede inward paths. Straight strips, qualified open curves and nearly uniform nested convex rings now use source-derived adaptive paths. Continuously varying gaps, junctions and inward spiral connectors still need broader qualification; coverage and a real print remain to be verified.

  • Import, slice, and print workflow

    Complete the practical workflow on a real printer before the first public product release. Software geometry and browser checks do not complete the print stage.

  • First-perimeter point cleanup

    Continue reducing redundant trajectory points across broader topology and feature combinations, using the original unoptimized inset centerline. Keep cumulative deviation within 2% of nominal line width in every region, including acute corners. Check originally short segments below one line width first, then remaining candidates. Preserve features and topology; introduce no new axis crossings or self-intersections.

    Printed bead coverage and overlap are deferred to a separate phase.

  • Direct analytic first inset

    Develop source-first cleanup before an independent inset, retaining the untouched source perimeter and emitted trajectory for future width changes. One cumulative 2% limit remains measured against the original inset; cleanup must preserve thin features and genuine offset splits. The public slicer still uses the existing CPU outline. A source-first candidate is undergoing independent review: local narrow-neck cases improved, while Ring remains slower. That candidate is not enabled in the public release. Ring wall 1.41 mm, hourglass, and shallow connector remain required references.

  • Immediate angle warnings

    Visible downward-facing model surfaces are red beyond the selected angle, using the existing render flow and shared geometry. The automatic support-analysis worker is disabled. Slice propagates source inclination through section boundaries into actual print segments without cumulative annotation limits; ordinary solid and Lines–Dots colors remain unchanged elsewhere. Exceptional unavailable correspondence is reported in status. Angle warnings do not evaluate bridges, certify support, or generate supports. Practical printing remains to be verified.

Decisions & discussion

Future proposals

The behaviors below need design and testing. They are not implemented in the current slicer.

  • Performance across Frame

    Compare full-flow elapsed time, peak memory, and correctness before and after changes throughout Frame. Report material slowdowns and avoid blanket expensive passes.

  • Nominal width first

    Plan paths around nominal bead width, with variable widths considered for exceptional situations rather than as the default.

  • Acute corners and residual gaps

    Work out routes for corners below 45°, tiny remaining gaps, and the extrusion transitions needed to enter and leave those regions.

  • Flat ends and corner extrusion

    Evaluate end caps and corner extrusion separately from centerline cleanup accuracy.

  • Boolean reliability and cost

    Compare correctness, full-engine elapsed time, and peak memory before and after on identical representative scenes, using repeatable runs. Prioritize faster broad-phase screening and local repair. Report material slowdowns and avoid blanket expensive passes. These investigations have not shipped fixes.
