# DXF interchange corpus

Format references: [Autodesk DXF reference](https://help.autodesk.com/cloudhelp/2020/ENU/AutoCAD-DXF/files/index.htm),
[binary DXF](https://help.autodesk.com/cloudhelp/2019/ENU/AutoCAD-DXF/files/GUID-FC1C3C69-DBC2-49E4-893A-000D6538C0FE.htm),
and [ezdxf encoding notes](https://ezdxf.readthedocs.io/en/stable/dxfinternals/fileencoding.html).

Practical uses: editable cutting/profile contours, engineering drawing geometry,
survey lines, nested CAD blocks, and polygon surfaces from CAD/mesh exporters.

`sources.json` pins nineteen upstream files from mozman/ezdxf at revision
`7b202613e0d689955b8932a22bcbcf68bdd684f0`, with original URLs and SHA-256.
The corpus includes AutoCAD-era R10/R12/R13/R14 data, binary files, BricsCAD,
dxflib and Leica examples, clockwise HATCH edges, nested dimensions and MINSERT.
The upstream MIT license is preserved in `LICENSE.ezdxf`.

Sixteen files must import supported geometry. Three files explicitly test atomic
rejection: `small_r14.dxf` is empty; `bin_dxf_r2000.dxf` contains only TEXT;
`visibility.dxf` contains text-only blocks. These are not counted as successes.

`*-generated.dxf` and `unicode-*.dxf` are test-authored fixtures, separate from
the downloaded corpus. They cover OCS/WCS, bulges, elevations, periodic/rational
and high-degree NURBS, CAD fit-only splines, nested affine shear/reflection,
arrays, hidden layers/entities, mesh/polyface grids, encodings and large drawings.

Compressed `.reference.json.gz` files contain independent ezdxf 1.4.5 analytic
curve samples and surface references, bound to the input SHA-256. They are not
generated by the Frame parser. The reference traversal preserves complete
Matrix44 products: ezdxf's recursive entity decomposition reconstructs nested
INSERT frames and loses shear in some nonuniform cases. Nonplanar source faces
have no unique internal triangulation; dedicated coverage checks preservation of
their source vertices, without projecting them to an invented plane.

Refresh downloaded originals with `node tests/fetch-dxf.mjs`. To regenerate the
authored fixtures and reference data, install test-only `ezdxf==1.4.5` and run
`python tests/dxf-reference.py`. Normal browser tests need neither Python nor
ezdxf. `npm run test:dxf` runs the focused real-WebGPU checks; the same checks
also run in `npm test` and `npm run test:stress`.
