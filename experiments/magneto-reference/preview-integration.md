## Exact requested authoring surface

- Native Magneto tag on an ordinary polygon owner: Material preset only. Show Reset Magnetization only when persistent state exists. Respect an explicit Frame Material; fallback display override must not alter it.
- Native finite Magneto plane with ordinary transforms, selection, navigation and gizmo. No separate Box, Domain, Air, Force, Torque or Section Plane object.
- Mode row: two native buttons Solve / Current Density.
- Current Density mode: one animatable signed Current Density field, displayed in A/mm squared.
- Solve mode: B, H, Magnetization and Saturation, each with Strokes / Section buttons. One combination active. Then Solve Frame / Animation.
- If an ordinary owner/group is selected: Force and Torque values, with those labels opening the existing Frame curves. No separate plot panel.
- No extra Quality, Range, Grid, Iterations, Tolerance, Direction, Bake or Advanced controls.

Do not map the synthetic reference material fixtures to NdFeB/steel names. Do not enable a native Solve action merely because the CPU reference tests pass.

## Integration boundaries

The native host provides evaluated occurrence identities, source/device signatures and borrowed canonical GPU resources. GPU preprocessing must classify geometry without stored normals and generate weighted object-local magnetic samples. Readback of all native triangles or a permanent CPU sample mirror is not an approved shortcut.

The production backend should satisfy the immutable opaque-lease lifecycle contract. Keep per-time physical remanence separate from disposable field/visualization cache. Use the shared Frame GPUDevice, no extra canvas, iframe, permanent RAF or independent scene graph.

Native snapshot validation must be repeated before asynchronous publication. Stop/cancel, deletion, source/device changes, transform edits, same-time re-solve, repeated clicks, native Undo/HASH reopen and timeline interruption need focused real-browser tests, followed by the exact candidate's standard/stress gates. Do not transfer old CPU or hardware passes to changed code.

The present CPU reference modules and fixtures are independent small-scene oracles for that work. conductor-current.js adds an explicit graph-only current basis with average cut-density semantics; it does not construct native conductor topology. The native authoring preview is already implemented separately; physical Solve, automatic preprocessing and production numerical qualification remain unavailable. CPU test results are not native browser/GPU or aggregate Frame passes.
