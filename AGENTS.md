# Frame

## Development

- Core runtime and embedded worker/popup factories live in `index.html`; follow actual embedded script boundaries when moving code. Plugins own runtime under `plugins/<id>/`. Use native WebGPU/WGSL; no Three.js, WebGL, CDN runtime or parallel scene/editor.
- Reuse existing kernels, transactions and GPU resources. Prioritize large-scene latency and bounded memory. No compatibility layers/migrations without a user requirement.
- Change UI only when requested. Code/UI/docs/fixtures are English. Draw icons at native dimensions without CSS/viewBox scaling.
- This is implementation context for the coding agent, not user help. Before editing, read the affected contracts here and the affected plugin AGENTS.md; locate their owning symbols/tests. Preserve behavior across input, evaluator, rendering, history and persistence. Keep one description per contract; omit release history, old measurements and setup walkthroughs. Shared plugin APIs belong in `plugins/AGENTS.md`; plugin-specific semantics belong only in that plugin's sole `AGENTS.md`. Constants and full schemas remain authoritative in code; verify them before changing a dependent path.
- Maintain `window.frameAI` with features. Missing automation/diagnostics found during a task belong in that implementation. New commands require schemas, validation before mutation and focused regression coverage outside runtime.
- Preserve unrelated work and user fixtures. After validation, commit task changes and push `origin/main` unless asked to keep local. Never force-push; verify remote commit. Application releases also require Pages/deployed-byte verification.

## Ownership, GPU data and history

- `FrameRenderer`/native engine own one GPUDevice and canonical polygon positions, indices, topology, normals, component masks and edit buffers. RAM holds authoring, spline cages/samples and bounded history. Explicit temporary import/export/algorithm readbacks are allowed; never retain a second CPU polygon scene.
- One logical vertex owns one position. Creases split shading aliases, not geometry; threshold is strictly above 44 degrees across buffer/paged initialization, animation, Boolean preparation and diagnostics. Stored STL normals are not authoritative. Buffer and paged-texture backends must keep shared topology across blocks; test both after topology/selection changes.
- Whole-object motion changes affine uniforms/bounds/revisions, not rest vertices. Partial component edits/nonuniform scaling invalidate angle partitions; missing element masks do not prove rigid motion. Occurrences follow source shading/bounds revisions and participate in moving passes even when spatially disjoint.
- Asynchronous publication checks scene/owner/geometry/device revisions, publishes a complete result and retires stale owned allocations. Submitted GPU work cannot be cancelled halfway. Keep existing display until a complete replacement is ready. Defer expensive maintenance during input; queued promises must not retain retired arrays.
- One chronological Undo/Redo covers frames, UI authoring, geometry, UVs/material masks and component selection. New edits clear both Redo branches. History RAM cap 256 MiB includes pending offload, reservations and Redo; UI snapshots <=64 MiB, metadata transforms <=100 actions. Oversized snapshots stay GPU-owned; no SSD history. No-op/cancelled unchanged gestures create no entry.
- Restore component IDs, owner hashes, component pivot/editing area and gizmo before returning from topology Undo; an immediate repeated Delete must work. UV/mask/rest resources stay leased while scene/history/clipboard needs them. Material assignment must not copy geometry.

## Affine frames, pivots and numeric editing

- `world = parentWorld * local`, Float64 column-major X/Y/Z/translation. Apply world delta to selected roots only. Reparent preserves full world affine frame and Undo restores parentage. Do not decompose away shear. Normals use inverse transpose and reflection sign; component delta is inverse(world)*delta*world.
- Pivot is a separate local matrix: editing it moves neither vertices nor object world frame. Freeze measured default before object transformation. Polar decomposition supplies the orthonormal gizmo basis without accumulating shear. Instance/Cloner source placement cancels about source pivot; Symmetry reflects authored source frames about its origin without subtracting source pivot.
- Primitive origins are authored, not tessellation bounds: square/cube minimum corner, cylinder/tube bottom centre, Text first-line left baseline, hardware mounting plane, Helix first point, stock assets ground origin. Explicit/frozen pivots win. Parameter edits/Make Editable/HASH must not apply origin compensation twice. Perspective creation uses an ordinary compensating pivot so initial PSR remains zero without moving geometry.
- Coordinate Manager World uses world frames; Object uses parent frame for Position/Rotation and object axes for Size/gizmo. Component dimensions are actual selected-control bounds, including true zero planar dimensions; only a lone tangent-bearing spline vertex includes tangent span. Share cached bounds across fields; oriented mesh measurements are serialized six-value GPU reductions with stale rejection.
- Scale is linear relative to the farthest selected boundary from pivot; uniform scale follows fixed screen diagonal. Interactive/numeric scale stays positive and invertible with a precision-dependent minimum. Excess drag below minimum must not accumulate: reversing immediately grows, including after HASH reload. Explicit affine skew remains intact.
- Shared numeric editor separates displayed rounding from authored values. Display-only zero tolerance is relative (16 machine epsilons at vector scale; angles one revolution, Position also selection size), converted to display units. Tiny real values/scalars remain representable. Focus/Enter/blur without actual typing never writes formatted text back; untouched scrub/arrows start from the underlying value.
- Text/paste use one bounded finite expression parser (Unicode digits/minus, scalar decimal comma); invalid/incomplete text restores last valid value. Explicit typed zero is an edit. Numeric/enum label diagonal scrubs use native transactions; Escape reverts. Each wheel adjustment completes its transaction. Field arrows retain their own modifiers, even over a viewport.
- Display units change labels only. Rescale +/- multiplies/divides selected roots by ten about pivots in one Undo. With no selection it scales all roots/placements about world zero and retains empty selection.

## Gizmo and gesture ownership

- Owning code: native engine gizmo plus `CURVE_GIZMO`, `frameCurves*Gizmo*`, numeric handlers and `FrameSpline`/`FrameMorph`. Preserve combined Move/Rotate/Scale mesh artwork, triangle hit testing/order and shared flat library. White centre scales uniformly, strips translate axes, extensions scale axes, inner areas move planes, outer quarter arcs rotate. Shape size/EXTFLAT/EXT3D are a shared hit/draw contract, not independent CSS dimensions.
- Reflect spatial parts toward camera; freeze reflection signs per view for the entire gesture. Each main/additional view has its own clipped SVG and cache keyed by view/basis/pivot/size. Activate an inactive view before handling its press. Wheel, middle/right navigation, double-click/context menu pass through overlays; body-level gizmos stay above helper hit areas.
- Explicit scale hits beat nearby controls. Otherwise active spline controls and a lone selected polygon vertex beat overlapping centre geometry. Lone hard vertex allows Move only (plus rotation in Pivot Edit); tangent-bearing spline vertex supports rotation/scale without moving the vertex. Tangent/control changes invalidate handle eligibility immediately. Compute eligibility once per view/draw, not with a stale cross-frame selection cache.
- Object/polygon selection commits on completed click; polygon vertices require selection before dragging. Orthographic spline controls permit first-press dragging; Perspective unselected points orbit, selected points/handles drag. Ordinary orthographic drag uses last gizmo operation; explicit tangent drag retains its own operation. Touch directly on gizmo bypasses navigation interception.
- Keep gesture-start frames/projection/pivot; apply only affected frames/bounds. Coalesce pointermove via RAF, apply final accepted position on release, serialize preparation/copy/snap completion. Escape, pointer cancellation, blur/hidden-document cleanup restore authored state and release captures/lock. A cancelled/ending gesture must never replay queued input.
- Clearing selection removes handles AND hit caches in every window. API/component-mode changes, Escape and background selection share cleanup. Browser rectangle commits publish actual engine owners even in component mode; cancelled previews restore prior owners/tags/focus.
- Q quantization and S snapping are mutually exclusive, including API writes. Move quantizes relative to gesture start; Scale quantizes size delta. Orthographic step is minor adaptive world grid, Perspective one displayed unit. Rotation uses radial 10/5/1-degree steps; skew 0.1. Axis/plane constraints remain active.
- Vertex snap uses visible non-selected geometry, GPU depth/distance/stable-ID ties, bounded winner readback; CPU only broad-phases bounds. Serialize requests/reject stale intermediate results. World-grid intersections remain world aligned in Object coordinates. Perspective screen-plane snap may take full world target; constrained axes stay constrained, orthographic movement stays in plane. Release moved-away candidates.
- Only completed single-vertex Move may auto-weld within its editable owner. Preserve destination ID, UV/corner/material lineage, storage backend and exact Undo; no auto-weld for multi-vertex/object/handle motion. Use existing coordinate-relative spline/Float32 polygon tolerances, not a new global epsilon.
- P/L toggles Pivot Edit; holding temporarily restores previous state on release. No scale in Pivot Edit. Auto Pivot chooses farthest world-bounds corner without moving geometry. Temporary component pivots survive surface rebuilds until selection changes; Morph Solve releases its requested pivot after fitting.
- Ctrl object transform copies independent descendant geometry/hierarchy; copy+motion is one Undo. Polygon Ctrl copies complete selected triangles only; Ctrl/Shift selected edge pairs extrude edges, Shift complete faces extrudes perimeter walls, no interior walls; lone vertex moves. Ctrl wins. Spline vertex-group Ctrl copies segments with both endpoints selected; edge Ctrl remains extrusion. Preserve new selected controls/provenance and Morph reference rules.
- During transforms cache stationary color/depth per view; redraw moving and touching/intersecting neighbors for coplanar ordering. Invalidate on camera/viewport/static changes, retire at gesture end; transparency disables this cache. Moving the whole scene provides no geometry saving.
- Screen-edge pointer lock starts only at an edge during held navigation/scrub, persists until gesture termination, and uses platform acceleration. Filter only recognized initial centre-warp contribution from coalesced motion; preserve residual/subsequent movement. No synthetic cursor/OS repositioning. Delayed acquisition after release must be cancelled.

## Views, selection and camera ownership

- `frameViewKind` resolves projection independently of window instance. Top looks -Y (+X right,+Z up), Right -Z (+X right,+Y up), Front +X (+Z right,+Y up). Perspective includes its world-Z reflection; projection, inverse rays, gizmo, winding and path-tracer reconstruction must use matching parity. Native camera frames remain proper rigid frames.
- One device/geometry, independent per-view cameras/shading/color/depth. Hover does not activate. Camera navigation redraws only affected views and creates no Undo; unrelated Undo must preserve navigated camera frames. Authored camera transforms remain history.
- Middle pan starts immediately; qualifying short middle-click restores pre-pan camera then toggles single/quad. Wheel/right zoom anchor under pointer; completed right navigation suppresses context menu until next press. Prefer visible mesh/spline hit; on miss use camera-normal plane through remembered surface, then finite XZ guide as initial fallback. Grid hits do not replace surface memory; replacement resets it. Late GPU pick cannot alter completed gestures.
- Solid is independent of Wire/Isoparms/Off; retain all six shading values in HASH. Both off suppresses geometry/component overlays, not grid/axes/helpers. Isoparms shows editable cages and polygon edges; Solid+Isoparms shares polygon barycentric pass with Solid+Wire, no second edge pass. Wire uses whole-object material colour (masked face colours excluded). Lines use physical-pixel thickness and bounded diamond rasterization, never detail-reducing LOD.
- Cage lines use geometric depth/less-equal without artificial depth lift; control-dot depth is separate. Selected generated-spline Instances show shared cages even in Polygon+Solid; per-occurrence transforms/selection remain independent. Strict occlusion has priority over filling a coplanar internal edge.
- Perspective far encloses actual visible scene plus fixed guide bounds (XZ [-1000,1000], positive axes 1000 mm). Scene-safe near cap prevents guide inclusion from clipping close geometry; do not enforce far/10000 when that would cut the scene. Pure splines/empty scenes must not acquire placeholder mesh bounds. Raster/Camera output/picking agree; path tracer has independent rays.
- Shared shader-local camera-relative arithmetic subtracts eye-Z 3.2 before multiplying positions, uses depth=-view.z and matching inverse translation. Public 144-byte camera layout stays unchanged; this does not recover Float32 camera-origin/geometry precision. Plugin opt-in contract is in plugins/AGENTS.md.
- Grid phase/spacing use Float64 CSS-pixel density and bounded viewport-local uploads; no world-coordinate Float32 phase or unbounded loops. Object marquee intersects actual GPU triangles/displayed curve/helper segments, clipped before projection; group bounds alone never select. Selection flash edges are clipped to each view frustum.
- Component picking/hover/marquee is restricted to active editable owners. Inactive surface first selects owner. Vertex surface clicks on active owner retain components; Edge surface clicks clear components but retain owner. Empty components in scene.select retains explicit owner. Connected selection follows clicked topology, not other islands; spline adjacency is authored segments, not shared filled cells. Document-level double-click routing includes newly appeared/body-level gizmos and detached view documents.
- Alt-left marquee works in every viewport; Shift adds, Ctrl/Meta toggles (latched on press). Curves owns its own marquee/key events before spline tools. Edge-to-Vertex retains endpoint selection. Focused fields own text/arrows. Use physical KeyboardEvent.code outside text editing.
- Enabled active Camera with PSR tracks on itself, transform ancestry or Target dependency owns main Perspective navigation, paused/scrubbing/playing alike. One keyed axis owns the whole evaluated vector. Empty tracks/unrelated attributes/static Target alone do not lock. Other windows/projections stay independent. Gate mouse/touch/wheel/focus AND final camera write; cancel held input/deferred work when ownership changes, do not resume stale deltas after unlocking. view.set camera rejects before mutation; inspect reports navigationOwnedByAnimation.
- Generic Target shortest-rotation aligns pivot +X, preserving stretch/pivot; no arbitrary world-up correction. Disable restores authored orientation; deleting Target freezes evaluated orientation. Camera leveling follows native camera policy. Target drags latch press projection so camera-follow cannot move the target again on release. Reject parent/target/generator cycles before mutation.

## Spline sources, evaluation and tools

- `FrameSpline`/`FrameGeometry` and embedded geometry worker: authored Float64 cubic cage -> geometric resolver -> native surface builder. Cage has controls/relative handles/segments/sequences/Border/approximation only, no primitive/axis/profile provenance or authoritative saved fill list. Cells are rebuilt from geometry even after detach/Make Editable/HASH.
- Coordinates/tangents affect planarity/nesting/fill: every edit re-resolves; reuse cell layout only when freshly resolved loops match. Cache keys include all controls/handles/sequences/Border/approximation, including in-place edits. Graph/global approximation/first build/explicit rebuild requires fresh resolution. Incomplete traversal/overflow is a diagnostic, never partial published fill.
- Exact planar/translation/ruled families use native fast paths, general nonplanar quads retain adaptive ribbon interiors even with straight edges. Approximate curve congruence must not switch a binary Coons correction. General 2..5-sided cells use Float64 workers, leaving one UI thread. Shared boundaries/logical IDs stay shared. Incremental GPU-to-GPU range copies/remapping must match fresh-build geometry; no permanent CPU triangles.
- Runtime construction plans flow worker-to-worker and disappear on conversion; they cannot become persisted evaluator provenance. Coordinator LRU is bounded (64 MiB surface cache; profile plans 8/16 MiB); worker retains only current batch. Display sample reuse requires same cage object, complete segment set and exact current control/handle/approximation fingerprint; otherwise resample.
- One active build/latest state wins. Cages update immediately during drag, surfaces publish current coalesced snapshots; final release is exact. Undo/Cancel invalidates source AND dependants and rejects delayed publications. Whole-generator affine motion reuses buffers; dependencies are generator-local.
- Patch owns generated surface, each editable spline child owns cage/accuracy; multiple sources resolve independently. Single-source patch hash may alias its source for tools; multiple-input mutation needs explicit source. Disabled Patch hides surface but exposes source; removing last source removes stale output immediately.
- Extrude/Lathe recursively evaluate independent child profiles in generator frame; separate children never accidentally become one Boolean, while contours within one source retain even-odd holes. Sweep consumes first two ordered nonempty spline inputs using authored profile pivot; missing inputs retire output. Lathe open ends use graph degree, not sequence breaks.
- Extrude direction derives from control geometry (stable plane normal or bounded covariance/extent fallback), not spline axes. Nonzero-offset planar cubic/zero-fillet fast path uses shared samples/cap triangulator; branches/nonplanar handles/fillets fall back. Large generated displays may omit cap rails above 1000 source segments; editable cage retains them. Keep last valid fillet surface/settings on invalid proposals.
- Native spline Instances feed Extrude/Lathe/Sweep/Patch without copying cages. Resolve occurrence/pivot frames including groups, shear/reflection; external source stays visible, only consumed occurrence hides. Source/pivot/ref edits invalidate, cycles reject. Extrude ignores solid/mesh/light/other generator children without hiding/poisoning them; mixed-group Instances hide only consumed curves. Empty valid-profile set is empty output, not stale geometry/error. Make Editable consumes occurrence, not external source.
- Draw first point/handle is a draft, not node/history; first segment publishes selected spline in one Undo. New empty spline follows active projection; never reorient nonempty spline. Finish keeps Vertex/owner. Ctrl-empty continues same spline; Ctrl-existing connects; Ctrl-hit cubic refines actual projected curve then de Casteljau splits without changing geometry. Numeric split zero clamps near lower endpoint, one near upper; omitted/null defaults midpoint, not numeric zero.
- Point+tangent selection gives point priority. Tangent movement rotates/scales siblings preserving ratios/branch angles; Ctrl/Shift breaks relation and mid-drag modifier change latches current relation without jumps. Soft/Hard affects chosen star only; Equal averages opposing vectors, equalizes branch lengths without changing branch directions. Control picking and drawn sprite sizes are separate; overlapping screen ties use nearest positive depth.
- Patch Polygon selects resolved filled cells/holes via GPU surface pick plus triangle-to-cell intervals, not projected average perimeter depth. Toggle Border sets all if any unmarked, otherwise clears; removes smaller connected region. Cell tools use oriented segment loops. Whole-cell extrusion removes old planar Border flags so hole walls close; edge-only keeps border semantics. Spline Connected follows authored segment graph.
- Outline uses existing Float64 planar/spatial offset kernel, explicit selected edges/cell loops or both-endpoint segments, never every edge touching one vertex. Worker session always recomputes from original cage; diagonal (dx-dy)/sqrt(2) crosses zero continuously. Branches become junction-ended paths; keep unrelated geometry and selection. Collinear cleanup affects only generated straight degree-two output. Shift/inner adds connecting rings. One completed gesture -> one Undo; Escape active gesture reverts.
- Bevel uses existing edge/spline vertex kernel, selected component domain and original gesture base, not accumulated previews. Interactive rounding is always on, Size only; zero restores. Degree-two spline corners trim by arc length/contact. Polygon Bevel is currently unavailable; do not resurrect it from older kernel docs. Preserve cell-loop orientation and clear obsolete edge selections.
- Mesh Line Cut uses finite projected region, optional current Edge/Polygon restriction and Visible Only GPU triangle-ID samples at physical-pixel pitch. Propagate shared edge splits into hidden/unselected neighbours to keep topology, without cutting their interiors. Pending picks drain before commit; preserve source-face masks/corner UVs. Loop/Close Hole commit on click; drag navigates, Escape/right cancels. Soft Selection display uses actual geodesic weights.
- Component Delete compacts orphan vertices and preserves pivots/UV/masks/storage backend, retaining empty polygon owner after last face. Deleting last spline segment removes spline node/source in same transaction. Morph topology edits are Modelling-only and adapt rest/key identities together.
- Boolean remains ordered generator over nested occurrences. Disabled/incomplete/failed output retires and reveals operands; moving operand out restores canonical arrays. Fast disjoint concatenation is eligible GPU path, not general union. Compare inherited/new exact-edge defects; new gaps/nonmanifold defects reject, trusted does not mean watertight. Preserve shared seam vertices/provenance. Long work shows stage/time, no invented percentage. Unite/normalized-volume pipeline is absent; do not restore removed APIs as compatibility.

## Persistence and files

- HASH is canonical addressed authoring: scene.records, owner/property XOR identities, typed binary data. Header: uint16 type + 16-byte ID + uint64 length, little-endian. Preserve Float32 geometry bits/indices and Float64 affine frames. Save source cages/parameters, not generated surfaces, normals/bounds/selection/history/jobs.
- Native parameters JSON stores animation/Morph/library/authorData; cages/materials/geometry remain binary. Add records only for authored features with defined identity/precision/limits/round-trip tests.
- Open preflights before replacement, then uploads one mesh at a time. Save streams readbacks <=4 MiB. Limits: 512 MiB decoded/record, 100000 owners, 1000000 records. Validate finite data/references/cycles; parent membership cannot depend on object order.
- Merge reuses native decoders/remapping and one append transaction; never reload/re-encode destination scene to merge another file.
- Scene formats: HASH/STL/OBJ/glTF/GLB/PLY/VTK/3MF/SVG/STEP/DXF. Geometry exports use visible evaluated occurrences; HASH retains authoring. STL maps Z-up to Y-up on import and reverses on export; OBJ is mm, glTF metres without axis swap. Unsupported required extensions reject before replacement. DXF text/ACIS/proxy data is diagnosed, not fabricated. Preserve asset license/attribution files.
- Plain Save writes HASH/reuses only a HASH binding; explicit format invokes Save As. scene.file reports binding/receipts. scene.file.request(open/save/saveAs) uses browser permission; without activation it queues the matching existing toolbar action. Synthetic click does not grant activation. Cancellation before import preserves binding; replacement clears it.
- Absolute-path scene.open/save/saveAs require an attached exact-grant local host. Grants come from tools/file-host.mjs --allow-file, never scene arguments. Chunked transfers save via flushed same-directory temporary file/atomic rename. Reconnect after navigation; inspect before retrying uncertain post-rename outcomes. Host setup: `tools/README.md`.
- Recent descriptors do not grant filesystem permission. Share embeds HASH in URL (16 MiB packed/512 MiB unpacked), with no upload/server storage; browser URL limits can be lower. Use files for large scenes.

- HASH matrix/pivot payload is 12 Float64 values, camera uses world-unit records independent of GPU normalization; saving an orthographic active view still stores Perspective camera from main view 0. Do not persist derived world/inverse frames or normalized camera offsets. Independent meshes remain independent records even if compression shares data.
- Native authoring JSON is a defined exception, not a catch-all scene container. Cages store actual source controls; saved cell hints cannot replace resolver. Native HASH load must not rerun STL welding/cleanup. Binary format/types/addresses/compression live in FrameHash; check codec before changing any serializer.
- Open decodes/preflights before releasing old scene; failure before replacement leaves current scene intact. After authoritative disposal/installation failure, data readiness stays false until explicit New/Open recovery. A pre-install records Map may be absent; readers treat it as absent metadata, never manufacture readiness. Only successful native install listener publishes ready after owners/materials/hierarchy/Docs rebuild.
- Save/Merge/ordinary commands reject incomplete nonnull documents; explicit replacement uses admission queue drain to recover null/failed state. Doc barriers and busy I/O still apply. Merge rolls back its published scoped root change only in the same document; rollback is not permission to overwrite later scene state.
- Save target/format changes only after successful completion; plain HASH Save never overwrites non-HASH export handle. Recent database is per app path, independent of versioned worker cache, and retains companions/handles with actual permission checks. Await MRU writes before returning file operation. - Imports use transient workers and bounded publication. STL exact-weld representatives are original points, cleanup tolerance cannot chain-grow. glTF missing optional images reports diagnostics but missing buffers/invalid/corrupt references reject. Companion resources are not independent scene formats. Per-corner seams/order/material masks must survive native conversion and export.
- PLY/VTK geometry-only import consumes unsupported attributes without pretending to retain them; 3MF uses physical unit/axis conversion, assemblies/face colours and package validation, no automatic repair. SVG imports outlined contours into native cubic cages, never executes scripts or invents geometry for text/filter effects.

Unsupported/inaccurate tessellation rejects before replacement. No hidden STEP equations/trim provenance/forced face lists in cage/HASH. - Offline cache prefers a complete coherent shell; never mix versions after failed fetch, erase user storage or reload unsaved work for updates. HTML/worker release stamps match; installed PWA identity stays Frame. Plugin lazy loading/cache behavior is in shared plugin contract.

## AI, author data and programs

- frameAI provides ready/listTools/call. Discover schemas instead of keeping command lists/counts in docs. Native hashes are stable, UI IDs session-local; units are mm/degrees/CSS pixels.
- Native mutations serialize and settle accepted editor/evaluator work. Mutations/export/share reject BUSY during manual gestures. Read-only observation flushes accepted live input without ending gestures or creating history. Diagnostics are bounded; volume alone does not certify a solid.
- authorData lives in root/owner parameters: {version:1,revision,records,retired?}. Identity is (owner,id), never name. Source/schema/binding/opaque payloads are inert unless explicitly opted into execution.
- Envelope caps: 512 records, 256 refs/record, 4 MiB JSON, depth 24, 4096 retired IDs. Validate plain JSON, safe finite numbers, Unicode and capacity before mutation.
- authorData.get/inspect/replace and fields.list/read/write use native epochs/revisions. CAS writes preflight all 1..128 distinct targets before one Undo transaction. No-op adds no history. Animated parameters are observations, not writable through this adapter.
- Executable descriptors are opaque format frame.scene-control, version 1, data {source,context,start,imports?,bindings?,params?}; source/imports/bindings index typed refs. Context main or worker:<name>; start defaults manual, ready opts into autostart. Source records alone stay inert.
- programs.describe/status/start/stop/restart/invoke/job/terminateContext own lifecycle. Poll queued receipts. ESM activate(ctx) owns per-activation state/exports/cleanup; ctx.import loads referenced source unchanged. Managed calls execute outside Frame FIFO. Frame AI API is JSON; native framePrograms.invokeDirect/postMessage supports structured clone/transfers.
- HASH saves program sources/descriptors, not heaps/timers/jobs. Main JS/direct frameCore access is not sandboxed or forcibly interruptible.

- Field CAS generation is conservative/global, not persisted per-field revision. Unrelated author edits may invalidate it; ABA cannot restore validity. Native history/replacement rotates epoch before async restoration. Persisted record revisions may rewind; runtime tokens must not. Frame observation is not completed simulation.
- Read-only fields/authorData stay in FIFO but bypass global evaluator settlement, do not load plugins/read GPU/create defaults, and reject native IO/history/gesture/not-ready states. ReadBatch captures one epoch/frame/index, retains request order/duplicates and reports unavailable entries without fabricated values. Accessors/reference fields/unsupported schemas are not ordinary scalar observations; oversized aggregate replies reject, not truncate.
- Writable name/visible and declared params use same validation as native UI (UI numeric clamps, API rejects). visible is authored, not effective/Solo visibility. Exact param: keys preserve spaces/case/colons. Metadata schemas may exist before plugin runtime loads; never substitute default for missing/invalid own value. Explicit read-write declaration determines writable params.
- Reference remapping uses object-only owner map, separate from material/tag maps. Duplicate shares root records; clipboard captures transitive declared root dependencies at Copy time, Paste clones closure with fresh root IDs, Merge imports all incoming root records afresh. Missing root/external references stay explicitly unresolved to avoid accidental retargeting; source/opaque strings are never scanned as refs.
- Record deletion leaves tombstones. Reservation ledger survives Undo/Delete/owner disappearance within document: 4096 namespaces, 65536 allocated record IDs/document, 4608/owner (512 live+4096 retired). Pure preflight cannot reserve. Validate aggregate restoration/root union before history-stack movement or GPU allocation; explicit document replacement alone resets ledger.
- Synchronous authoringStamp is covered by shared plugin contract. It cannot replace geometry capture or CAS; failed native commits conservatively invalidate without promising rollback. Post-settlement completed:true receipt requires reread before retry, not duplicate execution.
- Program descriptor exact source/import/binding refs preserve native remapping. Runtime ESM is arbitrary JS: do not rewrite source/static import strings, infer module dispose hooks, or pretend direct frameCore access is revocable. activate closure owns independent instance state; module globals are shared per source revision/realm. Restart activation does not reset module globals; terminating shared Worker affects every instance in that realm.
- Managed invalidation precedes cleanup; API admission checks generation after awaits. Stop does not wait for arbitrary async cleanup/initialization and cannot revoke already admitted effects. Registered late resources clean immediately. Unsettled hooks remain counted after cancellation; revoked Blob URL does not unload ESM namespace. Native invokeDirect/postMessage detach accepted transfers synchronously; JSON jobs reject typed/cyclic/accessor results.
- Bound retained modules (512 revisions/16 MiB source per realm), instances (512), Workers (32), in-flight hooks (128/realm), resources (1024/activation), jobs (128 history/64 ordinary unfinished), JSON results (64 KiB/8192 values/depth 24). Control stop/termination retains reserved admission; module cache survives document change and main cache requires reload on limit. Cleanup failures are diagnostics, not silent successful reclamation.
- Empty runtime/source inspection starts no Workers/timers/pollers. Unchanged activations survive temporary native readiness fences; changed dependency restarts, disabled suspends, visibility does not. Document replacement retires instances and named Workers, retained page lifecycle uses new host identity. No implied panel/subscription/frame/export/completed-simulation capability.
