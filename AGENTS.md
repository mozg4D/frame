# Frame

## Development

- Core runtime and embedded worker/popup factories live in `index.html`; follow actual embedded script boundaries when moving code. Plugins own runtime under `plugins/<id>/`. Use native WebGPU/WGSL; no Three.js, WebGL, CDN runtime or parallel scene/editor.
- Reuse existing kernels, transactions and GPU resources. Prioritize large-scene latency and bounded memory. No compatibility layers/migrations without a user requirement.
- Change UI only when requested. Code/UI/docs/fixtures are English. Draw icons at native dimensions without CSS/viewBox scaling.
- Object creation artwork and Objects Browser names share `frameObjectPalette` family accents. Each creation icon has one family hue; curves and surface builders use related cool hues, while errors may override names in red. Selection uses the row background. Gizmo idle opacity is shared by viewport and curve-editor handles; hover remains fully opaque.
- This is implementation context for the coding agent, not user help. Before editing, read the affected contracts here and the affected plugin AGENTS.md; locate their owning symbols/tests. Preserve behavior across input, evaluator, rendering, history and persistence. Keep one description per contract; omit release history, old measurements and setup walkthroughs. Shared plugin APIs belong in `plugins/AGENTS.md`; plugin-specific semantics belong only in that plugin's sole `AGENTS.md`. Constants and full schemas remain authoritative in code; verify them before changing a dependent path.
- Maintain `window.frameAI` with features. Missing automation/diagnostics found during a task belong in that implementation. New commands require schemas, validation before mutation and focused regression coverage outside runtime.
- Preserve unrelated work and user fixtures. After validation, commit task changes and push `origin/main` unless asked to keep local. Never force-push; verify remote commit. Application releases also require Pages/deployed-byte verification.

## Ownership, GPU data and history

- `FrameRenderer`/native engine own one GPUDevice and canonical polygon positions, indices, topology, normals, component masks and edit buffers. RAM holds authoring, spline cages/samples and bounded history. Explicit temporary import/export/algorithm readbacks are allowed; never retain a second CPU polygon scene.
- One logical vertex owns one position. Creases split shading aliases, not geometry. Polygon meshes use their own Crease Angle (default 44 degrees); an edge strictly above that angle is hard. Preserve that contract across buffer/paged initialization, animation, Boolean preparation and diagnostics. True Spline Patch cell interiors stay smooth and shared seams split where cross-tangent planes lose continuity, independent of the polygon angle. Stored STL normals are not authoritative. Buffer and paged-texture backends must keep shared topology across blocks; test both after topology/selection changes.
- Buffer normal jobs lease the shared scratch through metadata readback and dense packing; cold uploads, animation and idle crease maintenance share that lease. `diagnostics.normals` validates logical aliases and samples decoded corner normals with bounded temporary readback.
- An ordinary scene draw verifies material bindings, native visibility and geometry resources. A single Object view can reuse this state for camera motion. Bound surface and sampled-curve trees retain authored order. Dense views pack supported affine frames, native position/normal streams and classified edge indices on the shared GPU. Consecutive plain surface occurrences of one owner and source share an ordered affine buffer, including identical UV and masked material bindings. Cull by occurrence blocks and allocate individual draw bindings only when a fallback needs them. Binary alpha coverage stays in the opaque pass.
- A held control on a simple spatial Spline Patch can publish only its incident cells. The worker checks that changed cubic edges cannot alter cell membership. The renderer uses the adjacent unchanged faces for crease normals and line occlusion. Final publication, diagnostics, Cancel and history use the canonical geometry.
- Whole-object motion changes affine uniforms/bounds/revisions, not rest vertices. Partial component edits/nonuniform scaling invalidate angle partitions; missing element masks do not prove rigid motion. Occurrences follow source shading/bounds revisions and participate in moving passes even when spatially disjoint.
- `objectRelativeFrame` composes authored local paths below their lowest common transform ancestor, including Cloner parent policy and nested Instance pivots. Shared ancestor motion/constraints cancel; Target or Camera behavior on a unique path uses evaluated world frames. Generator signatures separate canonical geometry revision from affine frame revision and retain generator-local operand transforms. Defer transforming source cages until a changed generator signature admits reconstruction. A primitive solid depends on its own parameters and enabled state.
- Asynchronous publication checks scene/owner/geometry/device revisions, publishes a complete result and retires stale owned allocations. Submitted GPU work cannot be cancelled halfway. Keep existing display until a complete replacement is ready. Defer expensive maintenance during input; queued promises must not retain retired arrays.
- One chronological Undo/Redo covers frames, UI authoring, geometry, UVs/material masks and component selection. New edits clear both Redo branches. History RAM cap 256 MiB includes pending offload, reservations and Redo; UI snapshots <=64 MiB, metadata transforms <=100 actions. Oversized snapshots stay GPU-owned; no SSD history. No-op/cancelled unchanged gestures create no entry.
- Serialize history requests behind admitted pointer/geometry edits, including under Camera rendering. Preserve the current playhead for unrelated Undo/Redo and evaluate animated cameras there. Restore component IDs, owner hashes, component pivot/editing area and gizmo before returning from topology Undo; an immediate repeated Delete must work. UV/mask/rest resources stay leased while scene/history/clipboard needs them. Material assignment must not copy geometry.

## Affine frames, pivots and numeric editing

- `world = parentWorld * local`, Float64 column-major X/Y/Z/translation. Apply world delta to selected roots only. Reparent preserves full world affine frame and Undo restores parentage. Do not decompose away shear. Normals use inverse transpose and reflection sign; component delta is inverse(world)*delta*world.
- Pivot is a separate local matrix: editing it moves neither vertices nor object world frame. Group/Target defaults use their authored origin; polygon defaults measure their own local geometry, never descendants. Child edits freeze existing geometry-dependent ancestor pivots before affine motion or surface/cage publication; loading does not freeze incomplete defaults. Freeze measured default before object transformation. Polar decomposition supplies the orthonormal gizmo basis without accumulating shear. Instance/Cloner source placement cancels about source pivot; Symmetry reflects authored source frames about its origin without subtracting source pivot.
- Primitive origins are authored, not tessellation bounds: square/cube minimum corner, cylinder/tube bottom centre, Text first-line left baseline, hardware mounting plane, Helix first point, stock assets ground origin. Extrude defaults to its generated local-bounds minimum corner (empty output uses the origin), retained by Make Editable. Explicit/frozen pivots win. Parameter edits/Make Editable/HASH must not apply origin compensation twice. Perspective creation uses an ordinary compensating pivot so initial PSR remains zero without moving geometry.
- Coordinate Manager World uses world frames; Object uses parent frame for Position/Rotation and object axes for Size/gizmo. Component dimensions are actual selected-control bounds, including true zero planar dimensions; only a lone tangent-bearing spline vertex includes tangent span. Share cached bounds across fields; oriented mesh measurements are serialized six-value GPU reductions with stale rejection.
- Scale is linear relative to the farthest selected boundary from pivot; uniform scale follows fixed screen diagonal. Interactive/numeric scale stays positive and invertible with a precision-dependent minimum. Excess drag below minimum must not accumulate: reversing immediately grows, including after HASH reload. Explicit affine skew remains intact.
- Shared numeric editor separates displayed rounding from authored values. Display-only zero tolerance is relative (16 machine epsilons at vector scale; angles one revolution, Position also selection size), converted to display units. Tiny real values/scalars remain representable. Focus/Enter/blur without actual typing never writes formatted text back; untouched scrub/arrows start from the underlying value.
- Text/paste use one bounded finite expression parser (Unicode digits/minus, scalar decimal comma); invalid/incomplete text restores last valid value. Explicit typed zero is an edit. Attribute refreshes preserve the active numeric field and caret until editing leaves the panel. Cloner and Tree text applies on Enter or blur. Numeric/enum label diagonal scrubs use native transactions; Escape reverts. Each wheel adjustment completes its transaction. Field arrows retain their own modifiers, even over a viewport.
- Display units change labels only. Rescale +/- multiplies/divides selected roots by ten about pivots in one Undo. With no selection it scales all roots/placements about world zero and retains empty selection.

## Gizmo and gesture ownership

- Owning code: native engine gizmo plus `CURVE_GIZMO`, `frameCurves*Gizmo*`, numeric handlers and `FrameSpline`/`FrameMorph`. Preserve combined Move/Rotate/Scale mesh artwork, triangle hit testing/order and shared flat library. White centre scales uniformly, strips translate axes, extensions scale axes, inner areas move planes, outer quarter arcs rotate. Shape size/EXTFLAT/EXT3D are a shared hit/draw contract, not independent CSS dimensions.
- Reflect spatial parts toward camera; freeze reflection signs per view for the entire gesture. Each main/additional view has its own clipped SVG and cache keyed by view/basis/pivot/size. Activate an inactive view before handling its press. Wheel, middle/right navigation, double-click/context menu pass through overlays; body-level gizmos stay above helper hit areas.
- Explicit scale hits beat nearby controls. Otherwise active spline controls and a lone selected polygon vertex beat overlapping centre geometry. Lone hard vertex allows Move only (plus rotation in Pivot Edit); tangent-bearing spline vertex supports rotation/scale without moving the vertex. Tangent/control changes invalidate handle eligibility immediately. Compute eligibility once per view/draw, not with a stale cross-frame selection cache.
- Object/polygon selection commits on completed click. A plain component miss clears the component selection and gizmo on the active surface or background, including a click received while the preceding vertex Move is settling. Polygon vertices require selection before dragging. Orthographic spline controls permit first-press dragging; Perspective unselected points orbit, selected points/handles drag. Ordinary orthographic drag uses last gizmo operation; explicit tangent drag retains its own operation. Touch directly on gizmo bypasses navigation interception.
- Keep gesture-start frames/projection/pivot; apply only affected frames/bounds. Coalesce pointermove via RAF, apply final accepted position on release, serialize preparation/copy/snap completion. Escape, pointer cancellation, blur/hidden-document cleanup restore authored state and release captures/lock. A cancelled/ending gesture must never replay queued input.
- Clearing selection removes handles AND hit caches in every window. When edited-source replicas differ from the source-only component map, a Solid+Lines redraw invalidates that map before polygon picking rebuilds it. Ordinary Solid+Lines IDs remain reusable without another geometry pass. API/component-mode changes, Escape and background selection share cleanup. Browser rectangle commits publish actual engine owners even in component mode; cancelled previews restore prior owners/tags/focus.
- Adding an object from the Objects panel immediately selects its transform owner. In Vertex mode, Ctrl/Meta previews the point a click will insert on the selected editable polygon surface or edge, including in a passive view.
- Q quantization and S snapping are mutually exclusive, including API writes. Move quantizes relative to gesture start; Scale quantizes size delta. Orthographic step is minor adaptive world grid, Perspective one displayed unit. Rotation uses radial 10/5/1-degree steps; skew 0.1. Axis/plane constraints remain active.
- Vertex snap uses visible non-selected geometry, GPU depth/distance/stable-ID ties, bounded winner readback; CPU only broad-phases bounds. Measure snap distance from the projected Move target before applying grid or vertex snapping. Serialize requests and resolve the released position before accepting subsequent pointer motion. World-grid intersections remain world aligned in Object coordinates. Perspective screen-plane snap may take full world target; constrained axes stay constrained, orthographic movement stays in plane. Release moved-away candidates.
- Only completed single-vertex Move may auto-weld within its editable owner. Use the stationary vertex position. Remove zero-area incident faces and newly orphaned vertices, remap the destination selection, surviving UV corners and material masks, and retain the storage backend and exact Undo; no auto-weld for multi-vertex/object/handle motion. Use existing coordinate-relative spline/Float32 polygon tolerances. Spline welds retain the destination span when edited spans coincide; parallel curved spans with distinct loci can bound real cells.
- P/L toggles Pivot Edit; holding temporarily restores previous state on release. No scale in Pivot Edit. Auto Pivot chooses farthest world-bounds corner without moving geometry. Temporary component pivots survive surface rebuilds until selection changes; Morph Solve releases its requested pivot after fitting.
- Ctrl object transform copies independent descendant geometry/hierarchy; copy+motion is one Undo. Polygon Ctrl copies complete selected triangles only; Ctrl/Shift selected edge pairs extrude edges, Shift complete faces extrudes perimeter walls, no interior walls; lone vertex moves. Ctrl wins. Spline vertex-group Ctrl copies segments with both endpoints selected; edge Ctrl remains extrusion. Preserve new selected controls/provenance and Morph reference rules.
- During transforms cache stationary color/depth per view; redraw moving and touching/intersecting neighbors for coplanar ordering. Invalidate on camera/viewport/static changes, retire at gesture end; transparency disables this cache. Moving the whole scene provides no geometry saving.
- Screen-edge pointer lock starts only at an edge during held navigation/scrub, persists until gesture termination, and uses platform acceleration. Recognize acquisition from the native lock owner even if the change notification is delayed. Filter one initial centre-warp contribution within a coalesced batch and preserve residual and subsequent movement. No synthetic cursor/OS repositioning. Delayed acquisition after release must be cancelled.

## Views, selection and camera ownership

- `frameViewKind` resolves projection independently of window instance. Top looks -Y (+X right,+Z up), Right -Z (+X right,+Y up), Front +X (+Z right,+Y up). Perspective includes its world-Z reflection; projection, inverse rays, gizmo, winding and path-tracer reconstruction must use matching parity. Native camera frames remain proper rigid frames.
- One device/geometry, independent per-view cameras/shading/color/depth. Hover does not activate. Camera navigation redraws only affected views and creates no Undo; unrelated Undo must preserve navigated camera frames. A fresh bare Z press frames the selection. Releasing Ctrl or Meta while holding Z keeps the current view. Undo waits for a submitted Line Cut before ending the tool. Authored camera transforms remain history. Manual Camera navigation retains continuous yaw/pitch, pivot and depth after committing its frame; leveling preserves the authored up hemisphere through either pole.
- Object-copy Undo/Redo preserves existing camera matrices before restoring hierarchy records; restoring frame snapshots afterwards must not overwrite those navigated matrices. Newly restored copied cameras retain their authored placement.
- Selected/hovered spline edges replace the existing cyan stroke in native surface lines, wire raster and transparent surface shading. Independent cages recolor their existing line draw. Share the geometry-revision endpoint table and bounded compact edge-to-slot links; update highlight words only on actual selection/hover/frame changes. Occurrences retain independent highlight enablement. Do not add a selection geometry pass or classify polygon edges per frame.
- Navigation coalesces camera poses behind the last submitted camera frame. A drag uses the available press anchor on first motion, and a delayed pick cannot rebase the gesture. While the GPU is busy, wheel zoom can use the remembered surface or guide plane. Middle pan starts immediately and keeps its depth once motion starts. A qualifying short middle-click restores the pre-pan camera then toggles single/quad. Wheel/right zoom anchor under pointer. Completed right navigation suppresses context menu until next press. Prefer visible mesh/spline hit. On miss use the camera-normal plane through the remembered surface, then the finite XZ guide as initial fallback. Grid hits do not replace surface memory. Scene replacement resets it. Late GPU picks cannot alter completed gestures.
- Solid is independent of Wire/Isoparms/Off; retain all six shading values in HASH. Both off suppresses geometry/component overlays, not grid/axes/helpers. Isoparms shows editable cages and ordinary polygon edges. GPU classification hashes exact Float32 cage endpoint pairs once per geometry/display revision; masks and unique-edge bits are shared by occurrences, never rebuilt per frame. Baking to polygons clears these derived marks. Solid/Lines buttons change only their icons, not active backgrounds. Wire and Isoparms without Solid use the same part tint in every projection, slightly brighter than the major grid, using the whole-object material hue or a stable object/occurrence hue for neutral or unassigned materials. Generated Isoparms contours use the part tint in Object mode. Editable spline cages, selection and hover retain their editing colours. Lines use physical-pixel thickness and bounded diamond rasterization, without detail-reducing LOD. Dense plain occurrences use shared affine buffers, exact edge streams and occurrence colours. Picking creates individual edge bindings only for its candidates.
- Opaque Solid+Wire/Isoparms writes visible triangle IDs and camera-relative geometric planes alongside shading in the same geometry pass. Classified surfaces compute planes from canonical triangle corners only at covered fragments; never add per-vertex work over the complete scene. Ordinary polygons use the plain shader contract below. A foreign visible plane certifies contact only when both edge endpoints belong to it within Float32 arithmetic roundoff. Compare foreign occlusion at the actual interpolated line point, not pixel-centre depth. Active/passive views and transform backgrounds own and retire their plane targets (16 bytes/pixel); picking IDs remain unchanged. A native one-pixel line-list draws the classified cage strokes using their existing edge masks, canonical geometry and instance batches. Draw grid, surface lines, then editable cages in one read-only-depth pass after opaque plugins. Incident visible triangles certify an edge without depth displacement; a coplanar triangle sharing an endpoint also certifies its surface when sliver triangles have no raster samples. Bound only geometric Float32 roundoff, never fragment depth. Neighboring incident pixels preserve silhouettes only when the actual pixel occluder passes geometric depth/plane visibility, including occluders within the same owner. Visible polygon vertex markers use incident face IDs from the same view and frame while orbiting. Transform backgrounds and passive views preserve their own ID maps. No Z bias, temporal accumulation or polygon readback. Transparent materials retain the analytic surface path: perspective barycentrics multiplied by fragment reciprocal W before derivatives, never linear interpolation across the eye plane. Qualify native pixel coverage, occlusion, both storage backends and batching with tests/surface-wire-stability-browser.mjs (included in the spline-depth browser gate).
- Perspective plane-side visibility uses the actual view-space eye `(-viewport.zw,0)` after pan/cursor-anchored zoom; orthographic visibility uses the view direction. `tests/surface-wire-pan-browser.mjs` checks hidden/exposed strokes and fixed-eye pan invariance across zoom and both storage backends.
- Independent spline lines and unshaded cages use geometric depth/less-equal without artificial depth lift; control-dot depth is separate. Visible opaque plugin surfaces precede grid/cage lines in active and passive views; scenes without them retain the ordinary pass. Surface Instances follow the same line mode as their sources, without selection-mode exceptions. Per-occurrence transforms/selection remain independent.
- Solid+Wire/Isoparms polygons without classified cage masks use a plain surface shader specialized with `plainSurfaceWire`: perspective-correct barycentrics times fragment reciprocal W, physical-pixel derivatives and ordinary surface depth. Compile away cage-mask reads; do not draw their unique edges or prepare camera-dependent edge/triangle streams. Preserve all triangles, authored order and picking IDs; no distance thresholds or LOD. The surface shader also draws ordinary triangulation on classified meshes in Solid+Wire. It chooses lighter or darker strokes from unlit albedo, modulates the displayed surface colour and attenuates closely spaced triangles using the same derivatives. Covered-fragment derivatives provide the plain polygon planes for classified-line occlusion. Materials, filters, both storage backends and affine instance batches select the same path from their geometry classification. `tests/plain-polygon-lines-browser.mjs` checks visible edges, both modes, external/self occlusion and routing on both backends/projections. `tests/surface-wire-stability-browser.mjs` qualifies classified cages, touching seams, slivers, instances and eye-plane clipping; polygon-line masks compare against Solid to include antialias coverage.
- Perspective far encloses actual visible scene plus fixed guide bounds (XZ [-1000,1000], positive axes 1000 mm). Scene-safe near cap prevents guide inclusion from clipping close geometry; do not enforce far/10000 when that would cut the scene. Pure splines/empty scenes must not acquire placeholder mesh bounds. Raster/Camera output/picking agree; path tracer has independent rays.
- Shared shader-local camera-relative arithmetic subtracts eye-Z 3.2 before multiplying positions, uses depth=-view.z and matching inverse translation. Public 144-byte camera layout stays unchanged; this does not recover Float32 camera-origin/geometry precision. Plugin opt-in contract is in plugins/AGENTS.md.

Connected selection follows clicked topology, not other islands; spline adjacency is authored segments, not shared filled cells. Freeze its source-to-occurrence affine map at gesture start and conjugate the displayed delta back to the authored source, so the clicked result follows input and all reflections stay linked. - The Camera driving main Perspective suppresses its selected transform gizmo and hit state in that view. Other view instances retain their own gizmos. Enabled active Camera with PSR tracks on itself, transform ancestry or Target dependency owns main Perspective navigation, paused/scrubbing/playing alike. One keyed axis owns the whole evaluated vector. Empty tracks/unrelated attributes/static Target alone do not lock.
